# 使用与路径配置

## 窗口与封装预览

工作台和工具子窗口提供原生文字编辑右键菜单，不只依赖 WebView2 默认菜单开关。选中的普通文本可复制；剪切、粘贴仅用于可编辑位置。支持撤销、重做、全选，保留输入框选区，Esc 先关闭编辑菜单再处理底层窗口，对话框内同样可用。页面只能请求显示菜单，必须选择原生菜单项才执行固定编辑命令；没有页面可调用的复制、粘贴或剪贴板读取接口，不接受任意脚本。

点击菜单外的页面空白、滚动页面、调整窗口大小或切到其他窗口会收起右键菜单，不执行任何编辑命令；在弹窗内点空白仅收起菜单，不关闭弹窗。连续右键时旧关闭通知不会关掉新菜单。

封装管理使用一个原生窗口，内部通过标签与前进/后退切换，不再重复显示窗口标题栏。编号不匹配或配准失败仍能查看并排、叠加和图层对比，明确显示“仅预览，未配准”及具体编号/原因；这不代表能够安全替换。复杂焊盘、图形和铜皮由 KiCad 原生渲染；文件损坏、格式或本机渲染环境不受支持时显示失败原因，不以空白画面表示成功。

`KICAD_BUSY` 表示当前 KiCad 窗口没有及时响应。插件先重复只读探测最多 5 秒；恢复后继续，持续无响应则停止本次同步，期间不排队保存或关闭，也不写原理图字段。应先处理 KiCad 中的加载、阻塞弹窗或无响应情况，再重试，不需要因此丢弃未保存编辑。

### 手动焊盘适配

带 STEP/WRL 模型引用的封装也可平移、旋转并保存适配副本。3D 引用随封装调整位置和方向，保留缩放、显隐、透明度及高度；此操作不下载模型文件，缺失模型文件不妨碍二维封装保存。

封装管理的前进/后退箭头位于三个操作标签下方。“替换库封装”和“替换立创封装”共用手动操作：本地基准固定，目标可拖动、绕当前旋转中心旋转；十字按钮重新指定旋转中心。X/Y（mm）和角度也可直接输入，数值是相对初始预览的增量。

- “中心对齐”对齐两侧编号焊盘中心包络的中心，不以丝印或文字为中心。
- “1 号对齐”要求两侧各有唯一的 1 号焊盘，平移后使中心重合。
- “自动定向”按两侧唯一对应的引脚编号求旋转角度，不缩放、不镜像、不改变编号；完成后可再按中心或 1 号对齐。
- 引脚编号默认全部显示，可独立隐藏；重复编号仍显示，但不作为无歧义的自动定向依据。

展开“焊盘对应 / 手动适配”，勾选“保存工程适配封装”。逐个选择原端子对应的目标焊盘；编号相同时预填，不同编号可以手动对应。取消“参与对齐”只是不采用该点定位，仍保留电气对应。中心及自动方向只使用勾选的对应点；1 号对齐采用原端子 1 所对应的目标焊盘。至少一个对齐点，自动定向至少两个不重合点。

例如原 1～8 换成目标 1～10：对应 1～8，9、10 保留几何和原编号，首次未分配网络。原 1～10 换成目标 1～8：对应 1～8，对原 9、10 明确选择“放弃此端子”，再勾选确认。PCB 预检列出被放弃端子的网络、同网对象数量和物理接触未核验提示；有网络还须再次确认。原走线、过孔、区域不删除、不移动，请人工检查悬空、铜皮接触及 DRC。目标额外编号不能与原理图已有端子或映射后的编号冲突；信息缺失或重复歧义时停止。

应用时选择工程目标库与新名称（可合并现有库或新建工程库），保存真实变换后的适配副本。不同编号对应会把目标焊盘改为原端子编号，例如 A→1；预览显示原始→最终编号。原目标库/转换文件保持不变。同名不同内容须明确覆盖或另存，不能覆盖原基准或原目标文件。工作台保存不自动同步 CAD，随后显式同步原理图及 PCB。PCB 应用保留已批准的局部变换，不会再次自动拟合而抵消手动调整；源实例后来移动或几何改变须重新预览。

重复编号、一对多/多对一或最终编号冲突暂不支持。含 net-tie / jumper 焊盘组的特殊封装若需要改号，须先处理组定义；软件会明确提示，不静默改坏组关系。额外编号与原理图已有端子冲突、原理图端子无法核验时也会停止。保留额外焊盘或批准放弃端子不表示器件电气兼容，更新后仍需检查连接及 DRC。

预览与取消不写记录或工程库。普通同编号库封装仍可直接使用原库；仅改名仍保留原几何和确认状态。实际适配/换几何设为待确认；端子对应和视觉重叠均不代表电气兼容。

## 主表筛选与规格核对

Comment、Value、Footprint、页面位号的列头可打开筛选。每列支持多选，列内任选其一、列间同时满足，并可叠加状态筛选和全表搜索；页面筛选保留整个分组，不将一行按位号拆开。已选条件可逐项移除或清除，按工程记忆；不会修改分组规则或减少共享库存的总需求。

行号旁的警告标记表示已选 C 编码与**已保存原理图**的标称值或封装尺寸不符，悬浮或点击可查看位号、原理图要求及商品规格。`0.1uF` 与 `100nF`、`100K` 与 `100k`、`100` 与 `100R` 等按等效值核对；`DSMU:0603`、`R_0603_1608Metric` 与商城 `0603` 按尺寸核对。信息不足或复杂封装不能可靠解析时显示待核对，不判为一致。该功能不替代耐压、精度、介质、功率及引脚兼容性审查，不修改 CAD 或自动换料。

封装核对包含 `1808` / `4520Metric`，并与 `1812` 区分。问号提示具体指出来源和原因：已保存原理图字段未填写、原始 Value 无法唯一解析、商品参数未提供/多项冲突，或封装名称不是可自动比对的标准尺寸别名；不再笼统称值和封装都缺参数。电容 Value 明确写出 `C0G`、`NP0`、`X7R` 等介质要求时也核对，`C0G` 与 `NP0` 视为等效。Value 前带当前已验证商品型号且用逗号/分号分隔时，只剥离该型号前缀再解析后面的电气值；不能据此从型号文字猜值。

### 第一列的封装问号怎么处理

- `?` 是“规格待人工确认”，与已发现明确差异的警告分开。悬浮或点击查看具体来源、原始封装文字、还需核对的信息和建议，不直接认定错料。
- 例如 `插件,D2.5xL6.8mm` 这样的封装名称不能确定焊盘间距、钻孔直径和引脚方向；这表示**名称中缺少判断依据**，不代表商品数据手册或实际封装一定没有这些信息。贴片外形尺寸不因此被误列为缺少钻孔。
- 建议先保留当前本地有效封装；需要替换时，核对实际转换封装或数据手册中的编号、间距、尺寸和钻孔，再用封装对比流程确认。仅改名保留几何不证明新物料兼容。
- 这个问号是只读诊断，不更改“确认料”状态，不自动清空选型、换封装或同步 CAD；也不因用户看过提示就宣称通过。尺寸核对相符不替代完整几何或电气审查。

普通阻容的默认搜索词取标称值和封装尺寸，例如 `100k 0603`、`100nF 0402`，不带 `resistor`、精度或 `DSMU:` 等库前缀；原 Value 中的耐压/精度等要求仍保留，明确型号和 C 编码仍可直接搜索。电阻候选参数详情及筛选支持来源提供的温度系数、工作电压，没有来源值时不填造参数。

普通电感同样使用感值和封装尺寸搜索，例如 `4.7uH 0805`。Value 可使用 `4.7uH, Rated Current: 4.5A, Saturation Current: 4.6A`，缺失电流标为 `not specified`；电流标签不参与默认搜索，不妨碍感值核对。规格警告仍只核对感值和可识别的封装尺寸，电流要求需另外审核。Comment 为明确型号时仍保留型号搜索。

### 从物料参数补充 Value

点击主表 Value 右侧的左箭头，按需勾选当前主料参数，再核对预览并“应用”。电阻支持阻值、精度、温度系数、最大工作电压、功率；电容支持容值、额定电压、介质、精度；电感支持感值、Rated Current、Saturation Current、DCR、Type 和精度。默认只勾选 Value 已包含且商品提供的参数类型；未勾选不代表删除，不会自动加入全部商品规格。

例如 `5.1k, 5ppm` 勾选阻值和温度系数后可整理为 `5.1kΩ, ±5ppm/℃`；再勾选精度则为 `5.1kΩ, ±5ppm/℃, ±0.1%`。已有同类参数按所选值替换，不重复追加；未选限制及手写特殊备注保留。缺失或冲突参数明确提示并禁选，不从型号、推荐商品或其他 C 编码猜参数。带单位的参数标签会保留单位。

这是显式修改设计要求的操作，例如把原有 `250V` 替换成商品的 `50V` 前必须自行确认；工作台不替用户判断是否可以降额。取消不改记录，应用共用行编辑保存及撤回机制，不改确认状态或 C 编码，也不自动同步原理图/PCB。参数、分组或数据源在弹窗打开后改变会拒绝旧预览应用。电阻 Value 中 `5ppm`、`±5ppm/℃` 等不再妨碍阻值识别；该解析并不等于已经自动核对全部温漂、精度或电压限制。

“更换型号”先显示搜索列表的简要参数，再后台读取对应商品详情页的完整属性，不只截取列表固定几项；补取前验证 C 编码、型号和商品 ID，旧搜索的迟到结果不会覆盖新搜索。参数区标注“搜索列表”“搜索列表 / 历史缓存”或“商品详情”等来源。保留来源参数名、单位、完整值及厂商扩展属性。电阻额外列出温度系数、工作电压，电感列出直流电阻(DCR)、电感类型。缺项区分“正在补取详情”“详情尚未读取”“详情读取失败”和“详情页未列出”；失败可点“重试详情”，老数据没有商品 ID 时可点“读取详情”。不按型号猜值，也不把状态文字当作有效筛选值。参数列头支持对补齐后的属性筛选，选用主料会等待该候选正在进行的补取并保存完整参数。国内与海外来源的常用中英文名称、带单位标签会兼容识别，但工作电压不与额定电压混为一项。

订货渠道只展示和筛选该供应商实际返回的参数，不沿用商城主料的电压、温漂、DCR 等规格，缺项标为“渠道未返回”。界面的读取状态不会写入物料参数或原理图。旧缓存缺少结构化参数时兼容解析已有参数文本；新搜索或库存刷新不能用简要列表或未知占位符覆盖同编码、同型号已知的完整参数，也不借此修改确认状态或自动同步 CAD。主料与备选选用都会等待正在补取的对应详情。详情读取使用进程内短缓存（成功 10 分钟、失败 20 秒，最多 256 项、4 个并发），手动重试绕过已完成缓存；不改动浏览中的正式选料记录。开发接口和解析器见 `part_selection_product_details.py`，只允许固定商城域名和数字商品路径，不读取推荐商品的参数。

## 本地库存与套数

1. 打开“数据 → 导入本地库存…”（工具栏“本地库存”也可进入）。用文件夹按钮选择 Excel，或粘贴绝对路径，点击“预览”。支持 `.xlsx` / `.xlsm`，原表保持不变。
2. 默认识别含“商品编号”和“同型号已购合计”的工作表，也可手动选择。数量优先取“同型号已购合计”，表示**当前现存量**；不累加每条订单的发货或购买数量。与“已购合计”等旧列并存时仍优先规范列；`现存数量` 是通用表的兼容表头。厂家型号、品牌、封装、订单编号仅用于辅助核对。
3. 检查新增、更新、重复、待核实、无效行、待匹配数量。重复 C 编码的相同汇总数只记一次；冲突或无效数量的编码标为待核实，不计入可用库存。主表不再显示“未匹配”：有效 C 编码没有本地记录时显示 0，无编码显示 —，读取失败或数量冲突显示“待核实”。源记录是否已导入仍以导入预览和库存文件为准。
4. `D…` 等非 C 编码或无编号但有明确型号的记录，按完整型号/品牌/封装保留为待匹配，同型号汇总不相加。可在“待匹配库存”中填写明确对应的**工作台主料 C 编码**，离开输入框重新预览后确认；也可先保存而不匹配，此时不计入可用量。只显示同型号建议，不自动接受工程料号。映射后同编码数量冲突仍按待核实处理。同一来源已明确绑定后，重复导入沿用绑定，不能再次归到另一个编码；同型号来源中只要含无效数量，整组待核实。
5. 点击“确认导入”才写入。已有编码使用本次结余更新，不累计；本次文件未包含的历史库存保留。预览后源文件或库存改变则需重新预览，不能用旧预览覆盖新记录。
6. 工具栏“套数”默认 3，有效正整数立即生效、无需 Enter，重开保留。每行需求 = 单套用量 × 套数；同一 C 编码用于多行时，库存为**共享池**，按所有已加载分组的同编码需求合计判断充足/不足。保留需求计算，但主表库存格不展开本行及合计需求。NC / DNP 不消耗库存，列表筛选或隐藏行不减少已加载清单需求。这里仅比较，不自动扣减库存或建立出入库流水。

独立库存文件标准位置为 `BOM/选料工作台/本地库存.json`，不写商城缓存、原理图或 PCB。“设置 → 工程设置…”的数据目录迁移也包含库存的确认复制、冲突检查和备份；高级设置可单独指定库存文件。收货人、电话、地址不导入。合并后的库存列沿用显示、排序和列宽持久化。

主表“选料 / 库存”分别显示“商城库存 12,345”和“本地库存 100”，下一行直接显示“发货：1-3个工作日”等明确交期，无需展开详情。有库存不代表立即发货；总库存、仓库库存和合作供应商库存不能当成立即发货数量。优先使用渠道明确交期；只有独立的立即发货数量才显示“可立即发货 N”，分批交付保留各批数量，不硬编码“最快4小时”。缺少依据显示“发货时间待核实”，旧缓存由库存总量生成的4小时承诺也改为待核实；缓存中的真实工作日交期保留，读取不改选料或确认状态。

商城库存和本地库存不相加。有效 C 编码在本地无记录时显示 0；读取失败或数量冲突显示“待核实”，不能当作零库存；无编码显示 —。商城未查询、查询失败与真实零库存也分别显示。套数、同编码跨行共享库存及需求计算保留，不在主表铺开需求、缺口或余量，也不自动扣减库存。主表“库存 ≥ 100”只表示原有数量阈值，不承诺立即发货；采购前核对商城的最新交期和数量。

数量充足不表示型号、参数或引脚兼容，已有主料仍需核验。公式缓存缺失、负数、小数数量会提示来源行，在表格软件中核实保存后再预览。当前限制 20 MB 文件、100 MB 解压内容和 50,000 行明细。

## 列表视图

“选用物料 / 供货”和“本地库存”合并为“选料 / 库存”：上方是“更换型号”、C 编码输入框和商品链接图标，下方显示两类库存。删除原查询按钮和清空叉号，编码仍可选中删除。编码沿用行编辑保存队列，保存成功后立即查询；相同编码的同时查询合并，其他行查询不被取消，旧响应不覆盖新编码。查询不改变确认状态，真正换码或清空才沿用既有选料规则。失败可点击简短状态重试；局部刷新保留焦点、列宽及滚动位置。

供应商、订货链接、真实订货交期、仓库分布及查询时间收在“供货详情”中，点击展开；不显示最快几小时发货。MOQ/MPQ、价格列保持独立。升级时迁移当前及默认列表的列顺序、显隐与宽度，移除旧本地库存列设置，保留其他自定义配置。

“设置 → 插件更新…”采用“检查 → 下载并校验 → 重启并更新”流程。下载后可关闭面板继续选料，手动模式不会因此安装；自动模式仍在正常退出后安装。面板内显示成功检查时间、更新内容和错误；GitHub 限流会显示可重试时间，不通过重复点击持续发送请求。详细步骤见 [在线更新](kicad-plugin.md#在线更新)。

顶部命令菜单可用 Enter、空格或上下方向键打开，上下键切换项目，Home/End 到首尾；菜单栏左右键切换菜单，Esc 关闭并返回入口，Tab 离开。BOM 导出范围仍使用普通下拉框，可正常用方向键选择、Tab 移至导出按钮，不把它改成命令菜单。

启动读取数据源失败会在底部显示原因，点击工具栏“重新读取”（或“数据 → 刷新原理图当前数据”）重试；未成功加载列表前，库存查询和原理图同步保持不可用。筛选没有匹配器件时显示提示，可点“清除筛选”同时清空搜索和状态条件；不删除选料或勾选记录。“同步所选”仍只统计当前可见的勾选行，清除条件后原来的勾选重新显示。

若页面初始化失败且列表尚无可编辑行，原生关闭按钮仍可正常退出所属空闲后台。已有可编辑行但退出处理不可用时保留窗口，不绕过保存；后台有任务时同样拒绝关闭。

行内待同步提示保留 C 编码等字段的前后变化；物料参数变化只显示一次“物料参数更新”，不展开完整新旧参数。完整参数仍保存在选料记录并参与原理图同步。
同步预检与主表差异使用一致的物料参数来源：当前 C 编码已保存的参数优先，否则读取同编码缓存，不借用旧料号参数。预检固定本次参数；相关参数在执行前改变须重新预检，单纯现货数量、价格或查询时间变化不使预检失效。同步会回读核验实际字段，只有仍有真实差异才继续提示待同步；同步本身不改变确认料状态。

顶部“列表视图 → 列设置”面板中的“自动调整列宽”按当前可见内容重新计算列宽并记忆设置，不改变列顺序或隐藏列；也可双击表头右侧边缘只调整该列。

## 显式启动工程

```powershell
python -m pip install -r tools/kicad_plugin/desktop-requirements.txt
python -B tools/kicad_plugin/desktop.py --project "E:/work/Board/Board.kicad_pro"
```

`--project` 接受绝对工程目录或工程文件。中文启动器 `tools/启动器件选料助手.bat` 转发 `--project` / `--config`；无参数且无 KiCad 入口上下文时弹工程选择器，不绑定源码父目录。插件入口连接失效时先核验当前管理器及原理图；无法唯一核验则提示重试，不误弹工程选择器。

已有配置直接指定：

```powershell
python -B tools/kicad_plugin/desktop.py --config "E:/work/Board/BOM/选料工作台/工作台配置.json"
```

只支持独立工作台，不再提供浏览器启动或自动回退。关闭窗口等同“文件 → 退出工作台”：先保存行编辑，再退出所属后台。“文件 → 重启工作台”会等待原端口释放后以同一工程和配置重新启动；搜索、转换、同步或输入法组字尚未结束时保留窗口并提示处理。路径表单的未保存配置会单独询问是否放弃。

后端也接受 `--project`；必须明确提供工程或配置，不从源码目录猜测。两参数同时给出时，配置的 project_root 必须与 --project 匹配。标准旧配置首次启动按下方步骤迁移，已有中文配置及自定义配置保留；新工程使用前核对配置和数据位置。

## 工程设置

### 原理图字段映射

在“设置 → 工程设置… → 原理图字段映射”配置各用途对应的工程属性，设置仅属于当前工程，保存后生效并在下次启动保留。默认留空自动匹配，例如 `值 / 数值 → Value`、`封装 → Footprint`、`参数详情 / 物料参数 → Description`、`立创料号 / C编码 → LCSC`，同时兼容常用英文字段大小写。已有非空标准属性优先，不从旧 `ALTIUM_VALUE` 自动取值覆盖当前设计。

每个输入框可从已有属性名称中选择，也可输入任意新名称，例如将 Value 对应到 `值` 或 `valjeue`。输入后无需 Enter，下面会显示匹配数量、示例值、需要创建的数量或冲突提示。清空输入恢复自动匹配；未保存取消不生效。多个非标准候选值冲突、多个用途占用同一个属性、占用 Reference/其他内置字段时停止并要求手动匹配，避免猜测覆盖。

保存映射和预览不会修改原理图。读取、替换选料、差异显示、行内/所选/全部同步及同步后的校验均使用同一映射；正式同步时才创建缺失且有待写入值的属性，新自定义属性默认隐藏。映射到中文“值”或自定义封装属性时，同步也更新 KiCad 内置 `Value` / `Footprint` 并校验两者，确保显示值和实际封装标识一致；封装仍须是有效的 KiCad 库标识，不将商城尺寸名称直接当库标识。原有其他属性保留，不自动删除或改名。数据来源仍默认为已保存原理图。

“原理图跳转 → 跳转后鼠标位置”提供“返回原来的鼠标位置（默认）”和“留在原理图画布”。保存并应用后对后续位号跳转立即生效；配置按工程保留，下次启动沿用。激活原理图不会把已最大化的编辑器还原成小窗口，普通窗口也不强制最大化，最小化窗口才会还原。

“更换型号”设置可开启或关闭打开候选窗口时自动发起的立创网页搜索，默认开启；关闭后仍可点击候选窗口中的“网页搜索”按钮手动搜索。列表主筛选按筛选组合记忆滚动位置，切换离开后再返回同一组合，会恢复该组合之前的位置；记忆保存在当前工作台浏览器会话中。

“确认料”状态保存时由服务端写入 `review_confirmed_at` 时间戳，显示在对应行；状态改为待确认或不确认后，仍显示上次确认时间。此记录保存在选料覆盖 JSON 中，不随筛选或页面刷新丢失；同一行分组内位号确认时间不同时会显示差异提示，悬停可查看各位号时间。

确认料状态保存只更新当前行及筛选统计，不重新生成表格。Comment、Value、Footprint 停止输入自动保存后，字段下方和“未同步原理图”明细立即显示相对已保存原理图的旧值 → 新值；连续修改不会把上一次网页输入误当旧值。改回原理图值即清除该字段差异；其他待同步改动仍保留。Enter 使用同一保存队列，仅分组发生变化时重新合行，不主动将行滚动到页面中央。

“有改动，请同步原理图”按字段及旧值/新值合并重复项：同组多个位号相同的 C 编码变化只显示一次，不展示对应 URL 或重复位号。不同旧值仍分别保留，原理图缺失器件继续提示数量；此简化只影响显示，逐位号差异与同步数据不删减。

Footprint 列把共用库名放在表头（例如“封装库：DSMU”），行内只输入 `1206`、`0201` 等名称；有多个库时显示“多库”，每行标出自己的库。只改名称继续沿用该行原库，输入 `其他库:封装名` 可指定其他已注册库；不自动替换其他行的库。无库名前缀的旧值和空白不自动添加库名，保存、搜索及同步始终使用完整标识。既有封装对比窗口中的目标库选择保持原有操作。

Comment、Value 或 Footprint 自动保存完成后，会按这三个字段重新计算行分组。字段与其他行一致时会自动合并；临时拆出的行字段一致后也会自动合回，不必按 Enter。正在编辑的一批字段全部保存后再检查分组，只有分组成员改变才重绘，并保留当前滚动位置。

日常入口统一在顶部“设置 → 工程设置…”，无需手改 JSON。默认只显示当前工程、数据来源、工程选料数据目录和封装转换器。文件名、原理图目录、BOM 匹配规则、临时运行路径和诊断信息集中在默认折叠的“高级路径设置”。当前工程只读，可点文件夹图标打开，不会误切换到其他工程；目标封装库仍在具体封装转换时选择。

每次启动默认读取“原理图当前数据”，指磁盘上已保存的原理图，不是编辑器尚未保存的内容；历史 CSV 配置和上次界面选择不再覆盖它。“导入 BOM 文件”需主动选择，保存并刷新后仅本次使用，再次启动或完整刷新仍回到原理图。历史导入文件路径保留，便于再次选取，不会仅因改数据目录而丢失。

“工程选料数据”默认在当前工程 `BOM/选料工作台/`，包含选料记录（主料、确认状态、备注、备选、订货链接）、商城库存/参数缓存、本地库存、位号清单、导出 BOM/改动表和同步记录。可选“自定义目录”并输入路径或点文件夹图标。主动修改目录会将四个数据文件的目标路径一并指向新目录；打开设置、修改无关项或直接手改 JSON 不会擅自统一已有自定义文件。独立文件位置会显示提示，在高级设置中仍可逐项修改，或点“数据文件放入所选目录”。“工程目录 / BOM / 选料工作台”和“恢复工程数据默认路径”恢复标准数据路径。

设置需按“保存并应用”，不采用行编辑的逐字自动保存。修改数据位置时在保存前询问是否复制；取消则不切换。确认后先在工程外备份再复制，保留原文件，目标有不同内容时拒绝覆盖。保存成功后点“完成并刷新”；搜索、转换或其他请求未结束时暂不允许切换。原理图、PCB、正式工程库均不迁移，配置文件本身保持原位置。

临时缓存和桌面环境默认继续在工程外，避免 KiCad 递归备份。runtime_cache、desktop_home 留空时使用启动环境变量或默认位置；指定路径时优先于对应环境变量。运行目录保存后使用“文件 → 重启工作台”，不移动旧运行环境。插件程序安装目录只读，改安装位置需安装器的 --plugin-dir 参数。

示例是供新工程参考的配置，不要用它覆盖已有工程配置：

```json
{
  "project_name": "Board",
  "project_root": "../..",
  "data_layout_version": 2,
  "schematic_dir": "DOC",
  "bom_dir": "BOM/选料工作台",
  "source_bom": "__schematic__",
  "lcsc_bom_pattern": "BOM/*LCSC*.csv",
  "input_refs": "BOM/选料工作台/位号清单.txt",
  "output_overrides": "BOM/选料工作台/已选物料与字段修改记录.json",
  "stock_cache": "BOM/选料工作台/立创库存与参数缓存.json"
}
```

| 键 | 路径基准与用途 |
| --- | --- |
| `project_root` | 相对配置文件所在目录；配置放 `BOM/选料工作台/` 时写 `../..`。旧 BOM 配置的 `.` 根目录兼容规则保留 |
| `schematic_dir` | 相对工程根目录，通常 `DOC`；原理图位于根目录时写 `.` |
| `bom_dir` | 相对工程根目录，保存导出和同步记录；默认 `BOM/选料工作台` |
| `source_bom` | `__schematic__` 或保留的导入 CSV/XLSX 文件位置；界面启动始终默认原理图，主动导入仅本次生效 |
| `lcsc_bom_pattern` | 相对工程根目录的 BOM 匹配规则，默认 `BOM/*LCSC*.csv` |
| `input_refs` | 相对工程根目录的位号输入文件 |
| `output_overrides` | 相对工程根目录的人工主料、确认、备注、备选与订货记录 |
| `stock_cache` | 相对工程根目录的库存/参数缓存 |
| `converter_executable` | 可选，转换器可执行文件，相对工程根目录或绝对路径 |
| `runtime_cache` | 可选，工程外同盘的绝对临时缓存父目录；程序追加工程哈希子目录 |
| `desktop_home` | 可选，工程外绝对桌面环境与日志父目录 |

上述路径项也支持绝对路径及环境变量、`~` 展开。`source_bom` 的特殊值不是实际文件；开发代码保留其 Path 兼容表示。设置 bom_dir 不会自动重写 output_overrides、stock_cache 等其他显式路径，调整时逐项核对。

菜单保存通过 /api/path_settings 校验并原子更新 JSON，保留未知工程选项与 project_root；表单带版本摘要，外部改过配置时拒绝覆盖。高级用户仍可直接编辑 JSON，但需先通过关闭工作台停止对应后端、备份后修改并用 --config 重启；仅刷新界面不会重启后台。升级前遗留的旧服务需手动退出一次，见 [旧版后台处理](troubleshooting.md#旧版后台仍在运行)。不要按端口号终止未核实的服务。

## 迁移已有记录

中文目录结构如下（文件按实际使用生成）：

```text
BOM/选料工作台/
  工作台配置.json
  已选物料与字段修改记录.json
  立创库存与参数缓存.json
  位号清单.txt
  原理图同步记录.csv
  采购BOM表_时间.csv
  选料变更记录_时间.csv
```

`已选物料与字段修改记录.json` 保存已选 C 编码、确认状态、备注、备选、订货链接及 Comment/Value/封装等字段修改。中文只用于文件与目录命名；配置键和 KiCad 属性名保持兼容，不翻译。JSON/TXT/JSONL 使用 UTF-8，CSV 输出使用带 BOM 的 UTF-8。

旧标准配置 `BOM/part_selection_config.json` 在工作台正常关闭后，下次从插件入口或 `--project` 启动时自动迁移；显式指定旧标准配置也会解析到同一中文配置。新配置重新计算相对工程路径，保留未知配置、原始属性和所有选料元数据。迁移前备份在工程外 `中文数据迁移备份/`，原文件继续保留供核对；目标存在不同内容、旧后台仍运行或旧数据在迁移后又改变时停止，不静默覆盖或另开一份空记录。旧英文副本不再是日常编辑入口，核对完再自行归档，不要同时运行新旧版本。显式自定义配置路径、数据目录及自定义文件名不强制改变，可在工程设置中统一。

推荐使用“设置 → 工程设置…”选择数据目录，保存时确认复制，由程序备份、复制后切换。若直接手改 JSON，**不会自动搬迁文件**：先备份原记录和配置，停止对应后端，将 overrides、库存缓存及需保留的同步日志复制到新位置，再修改各路径、重启并核对主料、备注、确认、备选和订货信息。保留原副本直到核对完成。若新路径为空，应先查明是否漏复制，未经确认不得新建空记录替代旧数据。

`原理图同步记录.csv` 在 `bom_dir`；诊断用 `原理图同步运行日志.jsonl` 在工程外 `runtime_directory(project_root)`，同步返回的 `runtime_log` 提供实际绝对路径。旧标准目录下的 JSONL 在升级时复制到工程外，后续不再写入工程；它不属于需提交的选料记录。列布局保存在独立工作台的 localStorage，重启保留；旧浏览器的布局不自动迁入。

临时缓存默认在工程同级的 `../.kicad-part-selection-cache/<工程名>-<路径哈希>/`。可在启动前设置：

```powershell
$env:KICAD_PART_SELECTION_CACHE = 'E:/KiCadCaches'
$env:KICAD_PART_SELECTION_HOME = 'E:/KiCadDesktop'
python -B tools/kicad_plugin/desktop.py --config "E:/work/Board/BOM/选料工作台/工作台配置.json"
```

CACHE 是绝对、工程外同盘的缓存父目录，程序追加工程路径哈希子目录；不能用跨盘目录或链接回工程。HOME 是绝对、工程外的桌面日志/环境基目录，默认 `%LOCALAPPDATA%/KiCadPartSelection`。两者不负责移动正式记录或库文件。

## 选料与确认

每行“确认料 / 同步差异”区域提供“撤回修改”。它只撤回工作台尚未同步的一轮修改：先预览将恢复的字段、主料、备选、订货、确认状态和备注，再确认执行；不会写入原理图或 PCB，也不会删除已经导入的工程符号/封装库。

新编辑会在选料记录中保存修改前快照，连续编辑沿用同一快照，重新打开工作台后仍可撤回；同步成功后清除对应位号的快照，下一轮编辑重新建立。仅修改确认状态或备注也支持撤回。预览后若工作台记录或原理图发生变化，需重新预览；有位号缺失时整行不执行。撤回前的完整记录备份保存在工程外缓存。

撤回后若会与其他行合并，并产生编码或确认状态冲突，程序列出相关位号并停止，不会让分组规则清空其他行的选料。只采用原理图某个字段时，会更新该字段的撤回基线，其他尚未同步的编辑仍可撤回；确认字段已经与磁盘一致的同步操作也会清理对应撤回快照。

旧版本已经产生的未同步记录没有精确历史快照，或快照属于此前已同步的一轮修改时，预览明确标注采用当前已保存原理图字段，只恢复可读取的字段、主料、备选与订货信息，保留已有备注和确认记录；不恢复已同步历史，也不猜测旧版本的完整编辑历史。下一次新编辑会捕获当前记录，不再沿用跨同步的旧快照。如果没有可撤回差异，会提示而不写入。仅改名也支持此撤回机制，撤回不删除已经发布的库文件。

独立工具窗口支持 Esc 关闭，嵌套封装弹窗优先关闭最上层；同步预检内的封装对比先返回预检。Esc 与原有关闭/取消操作共用保存与任务保护，不强行终止正在保存、同步或安装的操作；中文输入法组字时不关闭窗口。封装管理按位号组独立打开，同一行恢复原窗口，不同行另开窗口。关闭主工作台自动取消未应用的封装预览并关闭子窗口，实际写入或后台请求未完成时等待并自动重试；其他工具尚未保存的表单会要求确认放弃，拒绝后保留编辑。资料读取失败可在当前页重试，取消后迟到结果不会重新打开窗口。

页面位号列支持直接勾选页面名称，也可点“按页面拆分”后勾选整页或单个位号。页面复选框支持全选、取消和半选；跨页多选后，“拆出所选”把全部选中位号放到同一临时行，其余留在另一行。临时拆行便于对子组编辑，刷新仍按 Comment、Value、Footprint 重新归组；没有字段差异时会合回。

Comment、Value、Footprint、备注和手填 C 编码停止输入约 650ms 后自动保存，离开输入框立即保存，不必按 Enter。输入法组字期间不保存中间内容。候选搜索停止输入 600 ms 后自动查询，Enter 立即查询，支持粘贴、中文输入法与精确 C 编码；清空取消查询，输入变化使旧结果立即失效，查询中不显示“无结果”。C 编码要求完整的 C 加数字；保存失败保留未保存输入并提示，刷新离开前会提醒。自动保存只写本地选料记录，不自动同步原理图。同步、导出、重新读取和更换型号前等待本地保存完成。

工作台按 Comment、Value、Footprint 完全一致分组，一行一个主料 C 编码和确认状态。同组只有一个非空编码时补齐空白并设待确认；存在不同非空编码时清空整行并待确认；确认状态不一致也设待确认。读取原理图当前数据时会将统一结果保存到记录，整理前在外部缓存保存审计备份；历史 BOM 不写回当前选料记录。备注、备选、订货和来源保留。

点击“更换型号”搜索候选，可选主料、备选或订货；缓存不代表实时库存，采购前核对官网。候选按品牌、封装及具名参数筛选，同字段多选取并集、跨字段取交集；“有库存”按每个渠道报价的数量分别判断，不表示能立即发货，需同时核对该渠道交期。精确 C 编码不扩大为替代搜索。

封装列图标打开同一个“封装管理”窗口，先显示窗口再读取资料；“替换库封装 / 替换立创封装 / 库封装改名”用标签页切换，左上角前进、后退保留搜索、选择和编辑内容。选库列表与同比例对比图同页，图层菜单可展开；库封装按原有库坐标显示，不能把预览当成已经配准。立创转换仍沿用已保存 PCB 实例优先的配准规则。“库封装改名”只填改名前、改名后两个完整标识，例如 `DSMU:0603` → `DSMU:C0603`，目标库必须是工程已注册的库；不加载图像或联网转换，原封装读取和保存校验仍执行。同名不同内容仍须明确选择覆盖或另存。取消与返回不写库，应用后仅保存待同步 Footprint，不改其他选料字段或自动写 CAD；转换失败不影响本地操作。

候选窗口独立于工作台，可按住系统标题栏拖到工作台之外或另一块屏幕，边缘和角落支持缩放，标题栏提供最小化、最大化和关闭。点击工作台空白处会收起窗口，搜索仍可继续；点击右下角恢复条或原行“更换型号”会保留关键词、筛选、选项和已返回结果，不重新查询。切换另一行则开始该行的查询。叉号表示关闭本次查询，之后重新打开会按器件重新查询；退出或重启工作台会一并关闭工具窗口。正在保存主料、备选、订货或转换/确认封装时，关闭会提示等待。拖选搜索文字划到窗口外不触发收起。

搜索框下的信息栏合并查询状态、筛选标签与结果数量，窄窗口自动换行，不预留大块空白。搜索期间显示“查询中”或“已返回部分结果，继续查询”；商城及订货渠道暂未匹配后若进入补充检索，会显示“补充检索：查询中 / 已返回”。单个渠道无匹配不代表整个搜索为空，只有全部阶段结束且没有候选才提示“未找到匹配器件”。缓存先显示时标明正在更新；网络失败单独提示，不等同于无货。

物料参数摘要保留电气参数，并补充封装与尚未出现在参数详情中的品牌；不显示包装方式或器件类别。相同品牌不会重复追加。该摘要也用于同步到原理图 Description。

### 编辑后合并到已有行

例如 `4.7nF` 和 `4.7nF 50V` 原本各有选型，手动把前者 Value 改成 `4.7nF 50V`，且 Comment、完整封装标识也相同，会将修改行并入原有目标行。主料 C 编码、物料参数、备选、订货和确认状态默认沿用目标行，不因来源编码不同而清空；目标原记录不改，来源备注仍按位号保留。自动保存和 Enter 使用同一规则，状态栏提示合并目标；关闭重开后仍保持。目标仅有订货链接时沿用链接，不虚构 C 编码。

来源旧记录先存到工程外运行缓存 `row_merge_<时间>_<标识>/overrides_before.json`，`merge.json` 记录方向和修改字段；正式选料文件仍在配置的数据目录。合并不会直接写原理图，来源位号的旧值、旧 C 编码及参数改动仍在待同步中列出。只改名称但没有现有匹配目标时保留来源选型；目标本身多编码冲突不任意选一个。普通刷新遇到的无方向冲突仍按原先“清空冲突编码、设待确认”处理。

每行最多 5 个备选料，列表顺序就是优先级；主料、重复编码、空编码和第 6 个备选不能加入。备选可上移、下移和删除。原理图的 LCSC_ALT 保存有序编码，LCSC_ALT_INFO 保存型号、封装和参数摘要；库存只在缓存里更新。两端不一致时可明确选择采用原理图或同步到原理图。

无 C 编码的订货料使用下单 URL 作为身份，记录供应商、型号、封装和稳定参数；原理图属性 PROCUREMENT_URL、PROCUREMENT_INFO 保存链接与摘要。选择订货不会虚构商城 C 编码。动态库存及价格查询结果不作为原理图稳定参数，采购前须在渠道页面复核。

Value、Comment、封装默认不替换。选择替换 Value/Comment 时，阻容感采用可靠电气数值及 resistor/capacitor/inductor，其他器件采用完整型号；没有可靠数值则保留当前值。完整型号仍保留在物料参数。保存选料是保存待同步记录，后续仍须确认同步。

## 封装与工程库

历史 BOM 的位号映射由工程 JSON 的 `bulk_sync_ref_map` 显式配置，例如 `{"U56": "U28"}`；独立插件没有预置某个工程的映射。此配置只用于旧 BOM 的全表同步；“原理图当前数据”和明确勾选的同步始终按当前位号处理，不套用历史映射。使用旧 BOM 前须核对其位号版本。

Footprint 编辑框旁的“预览／管理封装”图标使用独立接口，先显示当前绑定本地库封装，再后台补齐已选 C 编码的立创转换结果，优先复用缓存；失败不影响本地预览、选库或改名，无编码也可本地操作。支持替换库封装、替换立创封装和仅改名保留原几何；预览、取消不改记录或库，明确应用后保存撤回快照、标记待同步。只修改 Footprint，不借重新选料覆盖 C 编码、Value、Comment 或物料参数。实际换几何设为待确认，保留几何的改名保留确认状态；若合行仍继承目标行的选型。

“更换型号”窗口的封装选项为“不替换、替换库内部封装、替换立创封装”，默认不替换；Value、Comment 也默认不替换。“仅改名”在主表封装管理中使用。转换和仅改名均优先从已保存 PCB 按位号只读提取实际封装至工程外，还原局部坐标和正反面；这与初始预览的绑定库来源明确区分。仅改名以铜皮焊盘的编号、局部坐标和方向作为共用判断；丝印/用户图形不同会提示并统一采用所选基准版本，不联网、不改原共享文件，不导入符号；找不到 PCB 实例才使用当前绑定库。立创转换按同编号焊盘校正方向、对齐焊盘中心包络中心，实际保存变换后的几何。原理图 Footprint 可能已经先于 PCB 更新，不能当成 PCB 实例的原始几何。找不到 PCB 文件/位号时退回原理图库；对齐基准也可手动选择同编号的工程库封装，恢复已发生偏移的器件。基准来源和 PCB 放置位置、角度、正反面在预览中显示。PCB 存在多个候选、部分位号缺失或铜皮焊盘布局不同须先处理/拆行，不能猜测。

中心不包含位号、文字和丝印，也不因焊盘圆形/方形或尺寸不同而偏移。同一行多个原封装共用转换/改名基准时，逐编号局部中心的绝对距离允许最多 0.000020 mm（20 纳米），兼容历史小数差异和原生变换舍入；不平移、旋转或镜像后再比较。超过此值仍拦截并列出焊盘、坐标、实际偏差及允许值，不因丝印位置要求拆行。此规则不改 PCB 更新的严格配准阈值。转换目标与基准的焊盘中心最大偏差超过 0.025 mm 显示黄色提示，可在核对差异与引脚功能后确认；不代表两者完全兼容。禁止自动缩放或镜像；编号不符须明确手动对应或放弃，重复编号歧义及原封装不可读仍拒绝发布。

对比窗默认同尺度叠加两种颜色的真实 KiCad 图形，可切换同尺度并排，分别控制各来源的图层、位号/值显隐和透明度。显隐不改正式库；切换显示不重新转换。预览、配准及库发布都校验源 PCB、库和暂存文件，外部变动需要重新预览。转换通过调整库内部几何保留基准的原点约定，库条目原点仍为 (0,0)、角度仍为 0；正常替换保留 PCB 实例的 X/Y、角度和正反面。必须先保存 PCB；不能从磁盘读取未保存的 PCB 编辑。工具不自动移动 PCB、走线或过孔。间距差异可能影响已有走线端点，更新 PCB 后仍需核查连线。

目标库已经可在对比界面选择：合并现有库、新建工程内库或独立转换库。示例中的 DSMU 只是原工程库名，其他工程使用自己的库。同名且内容相同直接复用；内容不同弹出“已有同名封装”，默认另存新名称，也可勾选共享库影响提示后覆盖已有封装。覆盖前在工程外备份，文件变化后须重新核对。不自动添加 C 编码后缀；取消不修改此次选料及工程库。已有历史后缀不会自动改名。

导入后的符号、封装与 sym-lib-table/fp-lib-table 是工程设计依赖，仍随工程管理。移动程序或缓存不应移除它们；选择外部记录位置也不代表库会搬迁。详见 [转换说明](easykiconverter.md)。

## 同步与导出

“重新读取”从磁盘原理图读取，不读取编辑器未保存内容；会切回原理图当前数据并清空当前筛选和勾选。“同步所选行”只写当前可见且勾选的位号，隐藏选择不参与；“同步全部”不受筛选限制。执行前确认范围、保存编辑器并备份，窗口归属不明或忙碌时停止。

同步仅更新属性，不替换已放置符号几何、引脚或 PCB。Footprint 字段变化后仍需人工核对，再单独更新 PCB；不要把同步原理图成功当成 PCB 已更新。历史工程专用位号映射不能用于新的明确勾选同步。

### 所选器件原位更新 PCB

“同步设计”统一提供“同步原理图 / 同步 PCB / 全部同步”，范围可独立选择所选行、筛选结果或全部器件；行内入口不扩大到其他行。“全部同步”先写原理图，成功后生成新的实时 PCB 预检，仍需确认才写 PCB。原理图成功、PCB 失败时只重试 PCB；结果待核验时不盲目重放。

PCB 差异分为字段更新、封装仅改名、更换封装和类型待核对。仅改名保留实时实例几何，不读取目标库几何；手写名称没有可信操作证据时不能推断为仅改名。同步 PCB 同时更新所选器件的 Value、Comment 和已映射物料属性，保留原有字段位置与样式，新属性默认隐藏。

当前支持的 KiCad API 事务缺少明确目标文档，PCB 写入前会安全保存并暂关本工程原理图，完成后统一保存、重开及定位。保存失败或源变化即停止，不丢弃未保存内容；不在中间阶段反复恢复马上又关闭原理图。

预检在后台执行，窗口立即显示动态进度条和总耗时/当前阶段耗时；“阶段耗时”可展开查看已完成步骤，包括连接 PCB、读取实时封装、逐器件核对、安全暂关原理图、提交、回读和恢复原理图。原生 API 不提供可靠完成比例，因此等待阶段不显示虚假百分比。完整流程仍可能等待原理图保存关闭与恢复；不能为缩短时间跳过安全保护。

确认 PCB 未打开时，由当前工程的 KiCad 工程管理器执行 PCB 编辑器命令；管理器未开时先打开对应工程。不会回退到独立启动 pcbnew.exe。管理器归属、菜单命令或响应无法核验时明确停止，保持现有编辑器；接口未启用、忙碌或文档歧义时不会猜测或重复打开。等待新 PCB 的接口就绪时只轮询 IPC，不反复执行进程扫描。

没有改动时不重放原生封装事务，自动保存重开仍执行；已经完成的封装替换不会反复换几何。完成判定读取实时 PCB，库路径或内容改变会失效，不依赖永久“已同步”标签。未解除 PCB 文档锁或存在无法核实文档的编辑器时，不自动重复打开；请先核实编辑器状态。

标准库封装与原实例原点或方向不同，可保留标准库，例如 `DSMU:1206`，由独立的 PCB 更新操作补偿实例放置，不生成偏移/旋转的适配库副本。

1. 在“替换库封装”页选好目标，应用工作台修改，再同步原理图。
2. 从原理图或 PCB 入口打开工作台均可。启用 KiCad IPC，点击 PCB 更新时只读发现本机接口，按工程路径、板文件及服务端身份核验后连接，不按入口或默认地址认定目标板。PCB 可以晚于工作台打开；只有完整核实目标未打开才自动启动，忙碌、歧义或身份不明时不重复启动，排除阻塞后重试即可。
3. 勾选要更新的行，在顶部选择“所选行”，点“同步设计 → 同步 PCB”。也可明确选择筛选结果或全部器件；预检列出实际范围。
4. 选择对齐方式，默认“中心对齐”：按铜焊盘中心包络对齐并根据同编号焊盘校正方向，保留目标库几何，允许焊盘偏移。核对封装中心偏差、逐焊盘移动量、新旧位置角度和尺寸/钻孔/层差异；走线不移动，需明确接受偏移并在更新后检查连接和 DRC。也可切换“焊盘原位”严格保持各编号焊盘位置。切换会重新预检并清除确认；旧响应不能覆盖新模式。可点行内“封装对比”，同窗叠加/并排查看所选模式的实际补偿效果，返回保留预检状态。预览不写库，勾选确认后才执行。
5. 同步完成后自动保存 PCB，核验磁盘内容，再正常关闭并从工程管理器重新打开、定位原理图器件。保存包括当前工程此前的未保存编辑；保存失败、对话框阻塞或工程身份不明会停止，不强杀或丢弃。重开会清空 KiCad 原生撤销栈，工程外保留更新前恢复材料。

### 自动保存与重开

同步原理图前先保存当前工程的原理图和 PCB，全部保存成功后才关闭相应编辑器及工程管理器。若保存带回的所选器件字段与预检不一致，会要求重新预检，不用工作台旧值覆盖它。仅格式化或工程窗口配置变化不会误当成器件修改。

PCB 仍通过已核验的原生事务更新；写后自动保存、回读文件，正常关闭当前工程后经管理器重开并核验完整封装。同步原理图与同步 PCB 仍分阶段确认，不自动更新未选器件、网络或走线。原来打开的 PCB 会恢复，最后定位本批第一个原理图器件。进度区显示保存、关闭、写入、重开、定位及各阶段耗时。

入口连接过期时只读核验当前工程管理器及原理图，再重新进入工作台；不会把其他同名工程的连接或令牌接入，也不因连接失败误弹工程文件选择框。窄窗口中的省略路径使用当前工程的 Windows 重启登记与显示文字交叉核验，不依赖进程最初启动的工程路径。

同工程若另有独立启动的编辑器，或其他独立编辑器的当前工程无法核验，将在关闭/外部写入前停止并提示先保存关闭该编辑器；旧启动命令行不能排除它后来打开了本工程。不会用强杀代替正常关闭。

X/Y、角度数字可能改变，验收依据是各编号焊盘的板上实际位置。保持实例 UUID、原理图关联、网络、正反面和已放置字段；不执行整板 F8 导入，不新增/删除其他器件，不改走线或自动修复 DRC。标准库只读，目标定义通过隔离的后台 KiCad 会话读取并按源文件内容缓存；首次读取可能较慢。

此流程使用当前打开 PCB 的实时数据，而非磁盘旧板。预检后移动器件、换库、修改记录或重开编辑器，必须重新预检。锁定、重复/缺失焊盘编号、方向歧义或接口无法安全处理的对象会阻止更新。“焊盘原位”模式还要求各编号焊盘间距误差不超过 **0.001 mm**；“中心对齐”不把间距变化冒充为零偏移，也不缩放目标封装或移动走线。两种模式均不等于电气或制造兼容。立创转换保存库的旧配准流程不与此 PCB 更新模式混用。

原理图关联核验从主文件沿 Sheetfile 实际层级读取，不以目录中的同名位号或孤立旧页面代替当前工程。兼容根 UUID 被重新生成但根页保留历史实例记录，以及 PCB 关联路径省略根 UUID 的形式；仍需页面 UUID 链、器件 UUID 和当前工程实例记录对应。缺失时提示具体位号或层级文件，不要求用户手改 UUID 来绕过检查。

已经错误更新并移位的器件不能靠当前数据猜回历史位置，应先用可信旧快照恢复。此操作不是历史位置恢复工具。写入前在工程外保存恢复材料，失败时只撤回本插件批次；如恢复无法确认，会明确报错并保留恢复目录，不覆盖整板或强制关闭编辑器。

发布前失败会撤回本次暂存。若原生提交回执丢失，先重新读取确认，不重复执行；若发布后始终无法验证，因为 KiCad 10 不能原子核验撤销栈归属，不会盲目撤销可能夹杂的用户新操作，而会保留未保存的编辑器和恢复材料，明确提示核查。

KiCad 可重新排列封装内自定义字段、焊盘和图形的保存顺序；校验忽略这种对象排列变化，但仍逐项核对完整内容及对象数量。自定义字段不应因此导致“暂存返回内容与预检不一致”，实际字段、几何、网络或坐标变化仍会阻止发布。

工作台的待同步原理图和待核对 PCB 信息分别保存。运行记录只说明某次编辑器更新结果，不是永久“PCB 已保存”标志；每次更新重新读取实时状态，撤销或重开后不依赖旧成功记录。不会因更新 PCB 自动确认选料或覆盖 C 编码、Value、Comment、物料参数。

BOM 导出菜单可按筛选、库存、确认和待同步状态选择范围，导出排除 NC；导出改动表用于复核。工程自身的生产 BOM 导出器由工程维护，不随插件分发。单元测试不能替代实际 KiCad 窗口、网络或转换器冒烟。
