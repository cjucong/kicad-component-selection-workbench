# 使用与路径配置

## 主表筛选与规格核对

Comment、Value、Footprint、页面位号的列头可打开筛选。每列支持多选，列内任选其一、列间同时满足，并可叠加状态筛选和全表搜索；页面筛选保留整个分组，不将一行按位号拆开。已选条件可逐项移除或清除，按工程记忆；不会修改分组规则或减少共享库存的总需求。

行号旁的警告标记表示已选 C 编码与**已保存原理图**的标称值或封装尺寸不符，悬浮或点击可查看位号、原理图要求及商品规格。`0.1uF` 与 `100nF`、`100K` 与 `100k`、`100` 与 `100R` 等按等效值核对；`DSMU:0603`、`R_0603_1608Metric` 与商城 `0603` 按尺寸核对。信息不足或复杂封装不能可靠解析时显示待核对，不判为一致。该功能不替代耐压、精度、介质、功率及引脚兼容性审查，不修改 CAD 或自动换料。

普通阻容的默认搜索词取标称值和封装尺寸，例如 `100k 0603`、`100nF 0402`，不带 `resistor`、精度或 `DSMU:` 等库前缀；原 Value 中的耐压/精度等要求仍保留，明确型号和 C 编码仍可直接搜索。电阻候选参数详情及筛选支持来源提供的温度系数、工作电压，没有来源值时不填造参数。

## 本地库存与套数

1. 打开“数据 → 导入本地库存…”（工具栏“本地库存”也可进入）。用文件夹按钮选择 Excel，或粘贴绝对路径，点击“预览”。支持 `.xlsx` / `.xlsm`，原表保持不变。
2. 默认识别含“商品编号”和“同型号已购合计”的工作表，也可手动选择。数量优先取“同型号已购合计”，表示**当前现存量**；不累加每条订单的发货或购买数量。与“已购合计”等旧列并存时仍优先规范列；`现存数量` 是通用表的兼容表头。厂家型号、品牌、封装、订单编号仅用于辅助核对。
3. 检查新增、更新、重复、待核实、无效行、待匹配数量。重复 C 编码的相同汇总数只记一次；冲突或无效数量的编码标为待核实，不计入可用库存。主表不再显示“未匹配”：没有可用的本地记录时按本地可用零展示，源记录是否已导入仍以导入预览和库存文件为准。
4. `D…` 等非 C 编码或无编号但有明确型号的记录，按完整型号/品牌/封装保留为待匹配，同型号汇总不相加。可在“待匹配库存”中填写明确对应的**工作台主料 C 编码**，离开输入框重新预览后确认；也可先保存而不匹配，此时不计入可用量。只显示同型号建议，不自动接受工程料号。映射后同编码数量冲突仍按待核实处理。同一来源已明确绑定后，重复导入沿用绑定，不能再次归到另一个编码；同型号来源中只要含无效数量，整组待核实。
5. 点击“确认导入”才写入。已有编码使用本次结余更新，不累计；本次文件未包含的历史库存保留。预览后源文件或库存改变则需重新预览，不能用旧预览覆盖新记录。
6. 工具栏“套数”默认 3，有效正整数立即生效、无需 Enter，重开保留。每行需求 = 单套用量 × 套数；同一 C 编码用于多行时，库存为**共享池**，按所有已加载分组的同编码需求合计判断充足/不足，并显示本行及合计需求。NC / DNP 不消耗库存，列表筛选或隐藏行不减少已加载清单需求。这里仅比较，不自动扣减库存或建立出入库流水。

独立库存文件标准位置为 `BOM/选料工作台/本地库存.json`，不写商城缓存、原理图或 PCB。“设置 → 工程设置…”的数据目录迁移也包含库存的确认复制、冲突检查和备份；高级设置可单独指定库存文件。收货人、电话、地址不导入。新列沿用既有显示/排序/列宽持久化。

主表本地库存充足时显示“现货充足”；不足或为零时，按本地结余加商城已查询的现货能否覆盖同编码总需求判断“现货充足 / 现货不足”，并列出本地现存、本行需求、同编码需求及本地缺口。商城未查询或查询失败时显示“商城现货待查询”，不将未知库存当作充足；本地数量冲突/读取失败仍保留待核实提示。

数量充足不表示型号、参数或引脚兼容，已有主料仍需核验。公式缓存缺失、负数、小数数量会提示来源行，在表格软件中核实保存后再预览。当前限制 20 MB 文件、100 MB 解压内容和 50,000 行明细。

## 列表视图

“设置 → 插件更新…”采用“检查 → 下载并校验 → 重启并更新”流程。下载后可关闭面板继续选料，手动模式不会因此安装；自动模式仍在正常退出后安装。面板内显示成功检查时间、更新内容和错误；GitHub 限流会显示可重试时间，不通过重复点击持续发送请求。详细步骤见 [在线更新](kicad-plugin.md#在线更新)。

顶部命令菜单可用 Enter、空格或上下方向键打开，上下键切换项目，Home/End 到首尾；菜单栏左右键切换菜单，Esc 关闭并返回入口，Tab 离开。BOM 导出范围仍使用普通下拉框，可正常用方向键选择、Tab 移至导出按钮，不把它改成命令菜单。

启动读取数据源失败会在底部显示原因，点击工具栏“重新读取”（或“数据 → 刷新原理图当前数据”）重试；未成功加载列表前，库存查询和原理图同步保持不可用。筛选没有匹配器件时显示提示，可点“清除筛选”同时清空搜索和状态条件；不删除选料或勾选记录。“同步所选”仍只统计当前可见的勾选行，清除条件后原来的勾选重新显示。

若页面初始化失败且列表尚无可编辑行，原生关闭按钮仍可正常退出所属空闲后台。已有可编辑行但退出处理不可用时保留窗口，不绕过保存；后台有任务时同样拒绝关闭。

行内待同步提示保留 C 编码等字段的前后变化；物料参数变化只显示一次“物料参数更新”，不展开完整新旧参数。完整参数仍保存在选料记录并参与原理图同步。

顶部“列表视图 → 列设置”面板中的“自动调整列宽”按当前可见内容重新计算列宽并记忆设置，不改变列顺序或隐藏列；也可双击表头右侧边缘只调整该列。

## 显式启动工程

```powershell
python -m pip install -r tools/kicad_plugin/desktop-requirements.txt
python -B tools/kicad_plugin/desktop.py --project "E:/work/Board/Board.kicad_pro"
```

`--project` 接受绝对工程目录或工程文件。中文启动器 `tools/启动器件选料助手.bat` 转发 `--project` / `--config`；无参数时弹工程选择器，不绑定源码父目录。插件按钮优先识别调用它的 KiCad 工程，不能唯一识别时要求选择。

已有配置直接指定：

```powershell
python -B tools/kicad_plugin/desktop.py --config "E:/work/Board/BOM/选料工作台/工作台配置.json"
```

只支持独立工作台，不再提供浏览器启动或自动回退。关闭窗口等同“文件 → 退出工作台”：先保存行编辑，再退出所属后台。“文件 → 重启工作台”会等待原端口释放后以同一工程和配置重新启动；搜索、转换、同步或输入法组字尚未结束时保留窗口并提示处理。路径表单的未保存配置会单独询问是否放弃。

后端也接受 `--project`；必须明确提供工程或配置，不从源码目录猜测。两参数同时给出时，配置的 project_root 必须与 --project 匹配。标准旧配置首次启动按下方步骤迁移，已有中文配置及自定义配置保留；新工程使用前核对配置和数据位置。

## 工程设置

### 原理图字段映射

在“设置 → 工程设置… → 原理图字段映射”配置各用途对应的工程属性，设置仅属于当前工程，保存后生效并在下次启动保留。默认留空自动匹配，例如 `值 / 数值 → Value`、`封装 → Footprint`、`参数详情 / 物料参数 → Description`、`立创料号 / C编码 → LCSC`，同时兼容常用英文字段大小写。已有非空标准属性优先，不从旧 `ALTIUM_VALUE` 自动取值覆盖当前设计。

每个输入框可从已有属性名称中选择，也可输入任意新名称，例如将 Value 对应到 `值` 或 `valjeue`。输入后无需 Enter，下面会显示匹配数量、示例值、需要创建的数量或冲突提示。清空输入恢复自动匹配；未保存取消不生效。多个非标准候选值冲突、多个用途占用同一个属性、占用 Reference/其他内置字段时停止并要求手动匹配，避免猜测覆盖。

保存映射和预览不会修改原理图。读取、替换选料、差异显示、行内/所选/全部同步及同步后的校验均使用同一映射；正式同步时才创建缺失且有待写入值的属性，新自定义属性默认隐藏。映射到中文“值”或自定义封装属性时，同步也更新 KiCad 内置 `Value` / `Footprint` 并校验两者，确保显示值和实际封装标识一致；封装仍须是有效的 KiCad 库标识，不将商城尺寸名称直接当库标识。原有其他属性保留，不自动删除或改名。数据来源仍默认为已保存原理图。

“原理图跳转 → 跳转后鼠标位置”提供“返回原来的鼠标位置（默认）”和“留在原理图画布”。保存并应用后对后续位号跳转立即生效；配置按工程保留，下次启动沿用。激活原理图不会把已最大化的编辑器还原成小窗口，普通窗口也不强制最大化，最小化窗口才会还原。

“更换型号”设置可开启或关闭打开候选窗口时自动发起的立创网页搜索，默认开启；关闭后仍可点击候选窗口中的“网页搜索”按钮手动搜索。列表主筛选按筛选组合记忆滚动位置，切换离开后再返回同一组合，会恢复该组合之前的位置；记忆保存在当前工作台浏览器会话中。

“确认料”状态保存时由服务端写入 `review_confirmed_at` 时间戳，显示在对应行；状态改为待确认或不确认后，仍显示上次确认时间。此记录保存在选料覆盖 JSON 中，不随筛选或页面刷新丢失；同一行分组内位号确认时间不同时会显示差异提示，悬停可查看各位号时间。

确认料状态保存只更新当前行及筛选统计，不重新生成表格。Comment、Value、Footprint 停止输入自动保存后，字段下方和“未同步原理图”明细立即显示相对已保存原理图的旧值 → 新值；连续修改不会把上一次网页输入误当旧值。改回原理图值即清除该字段差异；其他待同步改动仍保留。Enter 使用同一保存队列，仅分组发生变化时重新合行，不主动将行滚动到页面中央。

“有改动，请同步原理图”按字段及旧值/新值合并重复项：同组多个位号相同的 C 编码变化只显示一次，不展示对应 URL 或重复位号。不同旧值仍分别保留，原理图缺失器件继续提示数量；此简化只影响显示，逐位号差异与同步数据不删减。

Footprint 列把共用库名放在表头（例如“封装库：DSMU”），行内只输入 `1206`、`0201` 等名称；有多个库时显示“多库”，每行标出自己的库。只改名称继续沿用该行原库，输入 `其他库:封装名` 可指定其他已注册库；不自动替换其他行的库。无库名前缀的旧值和空白不自动添加库名，保存、搜索及同步始终使用完整标识。既有封装对比窗口中的目标库选择保持原有操作。

Comment、Value 或 Footprint 自动保存完成后，会按这三个字段重新计算行分组。字段与其他行一致时会自动合并；临时拆出的行字段一致后也会自动合回，不必按 Enter。正在编辑的一批字段全部保存后再检查分组，只有分组成员改变才重绘，并保留当前滚动位置。

日常入口统一在顶部“设置 → 工程设置…”，无需手改 JSON。默认只显示当前工程、数据来源、工程选料数据目录和封装转换器。文件名、原理图目录、BOM 匹配规则、临时运行路径和诊断信息集中在默认折叠的“高级路径设置”。当前工程只读，可点文件夹图标打开，不会误切换到其他工程；目标封装库仍在具体封装转换时选择。

每次启动默认读取“原理图当前数据”，指磁盘上已保存的原理图，不是编辑器尚未保存的内容；历史 CSV 配置和上次界面选择不再覆盖它。“导入 BOM 文件”需主动选择，保存并刷新后仅本次使用，再次启动或完整刷新仍回到原理图。历史导入文件路径保留，便于再次选取，不会仅因改数据目录而丢失。

“工程选料数据”默认在当前工程 `BOM/选料工作台/`，包含选料记录（主料、确认状态、备注、备选、订货链接）、商城库存/参数缓存、本地库存、位号清单、导出 BOM/改动表和同步记录。可选“自定义目录”并输入路径或点文件夹图标。主动修改目录会将四个数据文件的目标路径一并指向新目录；打开设置、修改无关项或直接手改 JSON 不会擅自统一已有自定义文件。独立文件位置会显示提示，在高级设置中仍可逐项修改，或点“数据文件放入所选目录”。“工程目录 / BOM / 选料工作台”和“恢复工程数据默认路径”恢复标准数据路径。

设置需按“保存并应用”，不采用行编辑的逐字自动保存。修改数据位置时在保存前询问是否复制；取消则不切换。确认后先在工程外备份再复制，保留原文件，目标有不同内容时拒绝覆盖。保存成功后点“完成并刷新”；搜索、转换或其他请求未结束时暂不允许切换。原理图、PCB、正式工程库均不迁移，配置文件本身保持原位置。

临时缓存和桌面环境默认继续在工程外，避免 KiCad 递归备份。runtime_cache、desktop_home 留空时使用启动环境变量或默认位置；指定路径时优先于对应环境变量。运行目录保存后使用“文件 → 重启工作台”，不移动旧运行环境。插件程序安装目录只读，改安装位置需安装器的 --plugin-dir 参数。

示例是供新工程参考的配置，不要用它覆盖已有工程配置：

```json
{
  "project_name": "Board",
  "project_root": "../..",
  "data_layout_version": 2,
  "schematic_dir": "DOC",
  "bom_dir": "BOM/选料工作台",
  "source_bom": "__schematic__",
  "lcsc_bom_pattern": "BOM/*LCSC*.csv",
  "input_refs": "BOM/选料工作台/位号清单.txt",
  "output_overrides": "BOM/选料工作台/已选物料与字段修改记录.json",
  "stock_cache": "BOM/选料工作台/立创库存与参数缓存.json"
}
```

| 键 | 路径基准与用途 |
| --- | --- |
| `project_root` | 相对配置文件所在目录；配置放 `BOM/选料工作台/` 时写 `../..`。旧 BOM 配置的 `.` 根目录兼容规则保留 |
| `schematic_dir` | 相对工程根目录，通常 `DOC`；原理图位于根目录时写 `.` |
| `bom_dir` | 相对工程根目录，保存导出和同步记录；默认 `BOM/选料工作台` |
| `source_bom` | `__schematic__` 或保留的导入 CSV/XLSX 文件位置；界面启动始终默认原理图，主动导入仅本次生效 |
| `lcsc_bom_pattern` | 相对工程根目录的 BOM 匹配规则，默认 `BOM/*LCSC*.csv` |
| `input_refs` | 相对工程根目录的位号输入文件 |
| `output_overrides` | 相对工程根目录的人工主料、确认、备注、备选与订货记录 |
| `stock_cache` | 相对工程根目录的库存/参数缓存 |
| `converter_executable` | 可选，转换器可执行文件，相对工程根目录或绝对路径 |
| `runtime_cache` | 可选，工程外同盘的绝对临时缓存父目录；程序追加工程哈希子目录 |
| `desktop_home` | 可选，工程外绝对桌面环境与日志父目录 |

上述路径项也支持绝对路径及环境变量、`~` 展开。`source_bom` 的特殊值不是实际文件；开发代码保留其 Path 兼容表示。设置 bom_dir 不会自动重写 output_overrides、stock_cache 等其他显式路径，调整时逐项核对。

菜单保存通过 /api/path_settings 校验并原子更新 JSON，保留未知工程选项与 project_root；表单带版本摘要，外部改过配置时拒绝覆盖。高级用户仍可直接编辑 JSON，但需先通过关闭工作台停止对应后端、备份后修改并用 --config 重启；仅刷新界面不会重启后台。升级前遗留的旧服务需手动退出一次，见 [旧版后台处理](troubleshooting.md#旧版后台仍在运行)。不要按端口号终止未核实的服务。

## 迁移已有记录

中文目录结构如下（文件按实际使用生成）：

```text
BOM/选料工作台/
  工作台配置.json
  已选物料与字段修改记录.json
  立创库存与参数缓存.json
  位号清单.txt
  原理图同步记录.csv
  采购BOM表_时间.csv
  选料变更记录_时间.csv
```

`已选物料与字段修改记录.json` 保存已选 C 编码、确认状态、备注、备选、订货链接及 Comment/Value/封装等字段修改。中文只用于文件与目录命名；配置键和 KiCad 属性名保持兼容，不翻译。JSON/TXT/JSONL 使用 UTF-8，CSV 输出使用带 BOM 的 UTF-8。

旧标准配置 `BOM/part_selection_config.json` 在工作台正常关闭后，下次从插件入口或 `--project` 启动时自动迁移；显式指定旧标准配置也会解析到同一中文配置。新配置重新计算相对工程路径，保留未知配置、原始属性和所有选料元数据。迁移前备份在工程外 `中文数据迁移备份/`，原文件继续保留供核对；目标存在不同内容、旧后台仍运行或旧数据在迁移后又改变时停止，不静默覆盖或另开一份空记录。旧英文副本不再是日常编辑入口，核对完再自行归档，不要同时运行新旧版本。显式自定义配置路径、数据目录及自定义文件名不强制改变，可在工程设置中统一。

推荐使用“设置 → 工程设置…”选择数据目录，保存时确认复制，由程序备份、复制后切换。若直接手改 JSON，**不会自动搬迁文件**：先备份原记录和配置，停止对应后端，将 overrides、库存缓存及需保留的同步日志复制到新位置，再修改各路径、重启并核对主料、备注、确认、备选和订货信息。保留原副本直到核对完成。若新路径为空，应先查明是否漏复制，未经确认不得新建空记录替代旧数据。

`原理图同步记录.csv` 在 `bom_dir`；诊断用 `原理图同步运行日志.jsonl` 在工程外 `runtime_directory(project_root)`，同步返回的 `runtime_log` 提供实际绝对路径。旧标准目录下的 JSONL 在升级时复制到工程外，后续不再写入工程；它不属于需提交的选料记录。列布局保存在独立工作台的 localStorage，重启保留；旧浏览器的布局不自动迁入。

临时缓存默认在工程同级的 `../.kicad-part-selection-cache/<工程名>-<路径哈希>/`。可在启动前设置：

```powershell
$env:KICAD_PART_SELECTION_CACHE = 'E:/KiCadCaches'
$env:KICAD_PART_SELECTION_HOME = 'E:/KiCadDesktop'
python -B tools/kicad_plugin/desktop.py --config "E:/work/Board/BOM/选料工作台/工作台配置.json"
```

CACHE 是绝对、工程外同盘的缓存父目录，程序追加工程路径哈希子目录；不能用跨盘目录或链接回工程。HOME 是绝对、工程外的桌面日志/环境基目录，默认 `%LOCALAPPDATA%/KiCadPartSelection`。两者不负责移动正式记录或库文件。

## 选料与确认

页面位号列支持直接勾选页面名称，也可点“按页面拆分”后勾选整页或单个位号。页面复选框支持全选、取消和半选；跨页多选后，“拆出所选”把全部选中位号放到同一临时行，其余留在另一行。临时拆行便于对子组编辑，刷新仍按 Comment、Value、Footprint 重新归组；没有字段差异时会合回。

Comment、Value、Footprint、备注和手填 C 编码停止输入约 650ms 后自动保存，离开输入框立即保存，不必按 Enter。输入法组字期间不保存中间内容；搜索框仍按既有查询交互工作。C 编码要求完整的 C 加数字；保存失败保留未保存输入并提示，刷新离开前会提醒。自动保存只写本地选料记录，不自动同步原理图。同步、导出、重新读取和更换型号前等待本地保存完成。

工作台按 Comment、Value、Footprint 完全一致分组，一行一个主料 C 编码和确认状态。同组只有一个非空编码时补齐空白并设待确认；存在不同非空编码时清空整行并待确认；确认状态不一致也设待确认。读取原理图当前数据时会将统一结果保存到记录，整理前在外部缓存保存审计备份；历史 BOM 不写回当前选料记录。备注、备选、订货和来源保留。

点击“更换型号”搜索候选，可选主料、备选或订货；缓存不代表实时库存，采购前核对官网。候选按品牌、封装及具名参数筛选，同字段多选取并集、跨字段取交集；仅现货按每个渠道报价分别判断。精确 C 编码不扩大为替代搜索。

候选窗口独立于工作台，可按住系统标题栏拖到工作台之外或另一块屏幕，边缘和角落支持缩放，标题栏提供最小化、最大化和关闭。点击工作台空白处会收起窗口，搜索仍可继续；点击右下角恢复条或原行“更换型号”会保留关键词、筛选、选项和已返回结果，不重新查询。切换另一行则开始该行的查询。叉号表示关闭本次查询，之后重新打开会按器件重新查询；退出或重启工作台会一并关闭工具窗口。正在保存主料、备选、订货或转换/确认封装时，关闭会提示等待。拖选搜索文字划到窗口外不触发收起。

搜索框下的信息栏合并查询状态、筛选标签与结果数量，窄窗口自动换行，不预留大块空白。搜索期间显示“查询中”或“已返回部分结果，继续查询”；商城及订货渠道暂未匹配后若进入补充检索，会显示“补充检索：查询中 / 已返回”。单个渠道无匹配不代表整个搜索为空，只有全部阶段结束且没有候选才提示“未找到匹配器件”。缓存先显示时标明正在更新；网络失败单独提示，不等同于无货。

物料参数摘要保留电气参数，并补充封装与尚未出现在参数详情中的品牌；不显示包装方式或器件类别。相同品牌不会重复追加。该摘要也用于同步到原理图 Description。

### 编辑后合并到已有行

例如 `4.7nF` 和 `4.7nF 50V` 原本各有选型，手动把前者 Value 改成 `4.7nF 50V`，且 Comment、完整封装标识也相同，会将修改行并入原有目标行。主料 C 编码、物料参数、备选、订货和确认状态默认沿用目标行，不因来源编码不同而清空；目标原记录不改，来源备注仍按位号保留。自动保存和 Enter 使用同一规则，状态栏提示合并目标；关闭重开后仍保持。目标仅有订货链接时沿用链接，不虚构 C 编码。

来源旧记录先存到工程外运行缓存 `row_merge_<时间>_<标识>/overrides_before.json`，`merge.json` 记录方向和修改字段；正式选料文件仍在配置的数据目录。合并不会直接写原理图，来源位号的旧值、旧 C 编码及参数改动仍在待同步中列出。只改名称但没有现有匹配目标时保留来源选型；目标本身多编码冲突不任意选一个。普通刷新遇到的无方向冲突仍按原先“清空冲突编码、设待确认”处理。

每行最多 5 个备选料，列表顺序就是优先级；主料、重复编码、空编码和第 6 个备选不能加入。备选可上移、下移和删除。原理图的 LCSC_ALT 保存有序编码，LCSC_ALT_INFO 保存型号、封装和参数摘要；库存只在缓存里更新。两端不一致时可明确选择采用原理图或同步到原理图。

无 C 编码的订货料使用下单 URL 作为身份，记录供应商、型号、封装和稳定参数；原理图属性 PROCUREMENT_URL、PROCUREMENT_INFO 保存链接与摘要。选择订货不会虚构商城 C 编码。动态库存及价格查询结果不作为原理图稳定参数，采购前须在渠道页面复核。

Value、Comment、封装默认不替换。选择替换 Value/Comment 时，阻容感采用可靠电气数值及 resistor/capacitor/inductor，其他器件采用完整型号；没有可靠数值则保留当前值。完整型号仍保留在物料参数。保存选料是保存待同步记录，后续仍须确认同步。

## 封装与工程库

历史 BOM 的位号映射由工程 JSON 的 `bulk_sync_ref_map` 显式配置，例如 `{"U56": "U28"}`；独立插件没有预置某个工程的映射。此配置只用于旧 BOM 的全表同步；“原理图当前数据”和明确勾选的同步始终按当前位号处理，不套用历史映射。使用旧 BOM 前须核对其位号版本。

封装支持保留、选择工程已注册本地库、立创转换。库选择只读编号/尺寸，点预览才渲染；立创转换先在外部缓存生成并比较。焊盘编号不符或原封装不可读时禁止替换；编号相同仍须人工核对尺寸与引脚功能。

目标库已经可在对比界面选择：合并现有库、新建工程内库或独立转换库。示例中的 DSMU 只是原工程库名，其他工程使用自己的库。同名不同几何另存，不覆盖共享旧封装。

导入后的符号、封装与 sym-lib-table/fp-lib-table 是工程设计依赖，仍随工程管理。移动程序或缓存不应移除它们；选择外部记录位置也不代表库会搬迁。详见 [转换说明](easykiconverter.md)。

## 同步与导出

“重新读取”从磁盘原理图读取，不读取编辑器未保存内容；会切回原理图当前数据并清空当前筛选和勾选。“同步所选行”只写当前可见且勾选的位号，隐藏选择不参与；“同步全部”不受筛选限制。执行前确认范围、保存编辑器并备份，窗口归属不明或忙碌时停止。

同步仅更新属性，不替换已放置符号几何、引脚或 PCB。Footprint 字段变化后仍需人工核对并从原理图更新 PCB。历史工程专用位号映射不能用于新的明确勾选同步。

BOM 导出菜单可按筛选、库存、确认和待同步状态选择范围，导出排除 NC；导出改动表用于复核。工程自身的生产 BOM 导出器由工程维护，不随插件分发。单元测试不能替代实际 KiCad 窗口、网络或转换器冒烟。
