## 路径配置

- 工程配置支持 project_root、schematic_dir、bom_dir、source_bom、input_refs、output_overrides、stock_cache、converter_executable；路径相对 project_root，project_root 相对配置文件。
- --config 与 --project 可手动指定；选择其他工程时必须验证配置归属，不猜测源码父目录。
- 工程外临时缓存可通过 KICAD_PART_SELECTION_CACHE 手动指定父目录，仍按工程哈希隔离；禁止指向工程内或跨文件系统，保障库事务原子发布。桌面日志/运行环境可通过 KICAD_PART_SELECTION_HOME 配置。
