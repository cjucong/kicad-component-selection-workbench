## 操作界面

封装管理页保存到工作台，不立即写 CAD；可直接进入同一同步流程。返回/前进保留已选库、搜索词、目标名称和预览设置。不以关闭再新开模态层模拟导航。

## 改动分类

分类依据是显式操作意图、来源及几何证据，不是名称字符串。

1. **封装仅改名**：新操作记录明确指定保留原几何，并保存原实例/局部几何签名、来源、改名前后完整标识及适用位号。PCB 应用时只改完整库标识，保留实例几何、位置、角度、板面、焊盘、图形、丝印、文本、网络及子对象 UUID。若原实例或源版本已改变，重新预检，不把历史意图强套在新对象上。目标命名对应的库文件仍须核验存在及发布版本，但不以读取/转换/渲染整个目标几何作为名称更新前置。
2. **更换封装**：明确使用本地标准库或立创转换几何。即使新旧名称相同，也不能视为改名。沿用中心对齐/严格焊盘原位两种模式、编号校验、板面处理、逐焊盘移动显示；库内容保持不变，调整 PCB 实例位姿。
3. **字段更新**：Value、Comment、编码、物料参数等逐项比较；长物料参数用“物料参数更新”，保留可展开明细。不因字段变化误触发几何替换。
4. **类型待核对**：旧记录缺少可信意图或几何来源时不猜。字段可以独立同步；含此类封装变更的 PCB 任务在写入前阻止，并引导重新选择“库封装改名”或“替换库/立创封装”确认意图。

同批任务按操作类型分组展示；一个器件可以同时有字段与封装变更。只改名保留确认状态；真实换几何仍遵循现有未确认规则。预览/取消不改变确认状态。

## PCB 字段语义

共用工程 `field_mapping` 读取目标值。Value 写 PCB 内置 Value；Comment 及其他自定义映射属性按名称更新，缺失则创建隐藏属性。显式映射为同一物理字段的目标值若相互冲突，预检拒绝并列出具体字段，不静默覆盖。

Value/Footprint 映射到自定义别名时，同时保持 KiCad 内置值/封装标识与映射属性一致，不只更新别名留下设计内置字段过期。封装映射属性的文字变化不能绕过几何操作分类。只写差异字段；无变化的器件明确计入“无需更新”，不制造修改或未保存标记。

Reference 不作为可写选料字段；保留坐标、层、可见性等原有字段呈现属性，已有属性仅改内容。创建属性默认隐藏，不让新文字堆叠在板面。缺失数据不自动清空旧属性；明确清空才生成清空操作。每个字段预览列出原值与目标值。使用稳定的符号实例路径及工程身份，不靠相同位号猜匹配。

PCB 单独同步以已保存原理图为设计来源；若所选器件仍有工作台待写原理图字段，确认页显示前置条件和“改为全部同步”，不隐式写原理图。全部同步先写原理图并回读核验，再重新生成 PCB 预检。

## 同步任务与部分完成

新增设计同步协调层，复用原理图事务及 PCB 原生事务，不建立第二套 CAD 写入代码。接口区分只读预检、启动任务、查询状态和继续未完成阶段。请求绑定工程、位号、映射版本、记录版本、来源签名及目标；一次操作生成任务标识，丢失响应只查询该任务，不重新提交写入。

阶段为：读取差异 → 原理图保存/关闭与写入核验（需要时）→ 连接/打开 PCB → PCB 预检 → 确认几何风险 → PCB 暂存/发布/回读。直接 PCB 目标省略原理图写入，原理图目标省略 PCB 阶段。

PCB 的最终确认必须基于原理图同步后的新源版本；先前预览仅供理解，不作为最终写入凭证。允许自动继续无几何风险的阶段；出现新的差异、身份不符或几何风险时停在明确确认页。

阶段结果独立记录。原理图成功而 PCB 失败显示“部分完成”，保留原理图结果，仅继续 PCB。重试前重新核验当前设计版本与实时 PCB；变更后旧令牌失效。PCB 发布结果不明时先只读对账，不能盲目重放、全局撤销或假装失败回滚成功。

进度来自真实阶段事件与明确完成数，不使用计时器伪造百分比。每行局部更新状态与差异，保留焦点、滚动、选择、列宽。

## PCB 自动连接和打开

连接发现分清：已连接、未打开、已打开但 IPC 未启用、忙碌/模态框阻塞、多会话歧义、断连、打开失败。记录探测结果，不吞掉所有异常统一显示“未找到”。

先复用已核验的当前会话；失效后再发现。每次写入仍核验服务端令牌、工程与文件、对象和源版本，连接缓存不降低安全校验。

只有可靠确认目标 PCB 未打开且唯一解析出正确 `.kicad_pcb` 时，才正常启动编辑器并等候 IPC。工程中存在多个目标文件不能猜测，提供文件选择。已有会话忙碌、IPC 状态不明或存在锁但无法确认归属时，不重复启动，不替用户关闭对话框。

自动打开仍无法获得 IPC 时给出明确“已打开，需启用 IPC”的操作提示；不擅自改运行中的全局 KiCad 设置、不要求从 PCB 入口重开工作台。启动的编辑器属于用户设计会话，不因工作台退出而关闭。

## 所有内嵌窗口独立化

将现有候选独立窗口机制扩展为宿主工具窗口注册表。包括封装管理/对比、同步确认/进度、工程设置、库存导入、字段映射/列表视图、撤回/Value 补参、插件更新等窗口；原生文件选择器保留原生行为。确认提示在所属窗口内处理，不另造无限层级原生窗口。

- 工具窗可拖到主窗外，支持系统缩放/最大化/关闭；正文尺寸响应式。
- 同类工具复用其窗口；相同器件恢复状态，不重新搜索或转换。
- 每个窗口绑定宿主和工程，只暴露完成该工具所需的窄桥接；URL、请求参数和消息来源均校验。
- 返回主表仅发送已验证结果并局部刷新，不让子窗直接修改任意文件或调用退出/更新权限。
- 主窗关闭/重启先收集所有所属窗口的未保存/任务状态，忙碌时保留窗口；不影响其他工程工作台或 KiCad。
- 子窗关闭后迟到请求不能使其复活或串入另一器件。最小化不丢任务、查询及输入。

网页预览中的拖动、独立浏览器窗口只演示交互；不将其宣传为已经实现可越界的原生窗口。

## 响应性能

已有只读实测：当前生产层级的一次身份解析约 4.745 秒，15 个文件；现有预检重复读取来源，存在可消除的重复解析。该数字仅作诊断基线，不代表承诺的固定耗时。

- 同一预检复用原理图文件解析、映射字段和实例路径快照；发布前再读字节核验文件集合及哈希，不能只比较 mtime。
- 库只读缓存按完整标识、源文件内容版本、板面分开；在应用前核验内容哈希。
- 批内相同目标库几何仅加载一次；只改名与只字段任务不启动隔离库几何读取进程。
- 网络转换与图形渲染不持有工程写锁；图形按需加载，界面与关闭/取消反馈不等待渲染。
- 使用可取消的只读请求与代次标识，过期结果不可应用。已进入写事务后明确不可中断，等待结果。
- 记录点击到窗口呈现、预检阶段及原生写入耗时，在同一合成夹具比较冷/热路径，报告实测而非猜测提速百分比。

## 验证与交付

先写失败回归，再实现。覆盖目标/范围分离、类型证据、无变化跳过、字段映射冲突/缺失/清空、仅改名完整对象不变、中心对齐风险确认、历史类型未知、源变化、部分成功、断连重试与发布结果不明。

IPC 测试覆盖正确工程已开/未开/忙碌/未启用/歧义/多工程/令牌隔离，不把忙碌认作未打开。原生合成工程实际验证两种入口、字段/仅改名/真实换几何、正背面、未保存编辑保留、单步撤销、保存重开。确认网络、走线、非目标对象不变，不自动保存整板。

窗口测试覆盖拖出主窗、缩放、多工具状态、最小化恢复、主窗退出/重启拒绝丢编辑、关闭后迟到结果、子窗权限边界；网页测试不能替代原生窗口验证。

执行全套仓库回归与专项浏览器/原生冒烟。完成后审查、提交、推送插件 origin main，重新安装并校验所有安装文件字节及转换器保留。只推源码和本机安装不是正式在线 Release，不据此宣称其他电脑已可更新。
