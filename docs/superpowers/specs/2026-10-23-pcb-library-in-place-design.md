# 标准库封装原位替换与所选器件 PCB 更新

日期：2026-10-23

状态：方案 B 已实现并通过隔离 KiCad 原生流程验证；完整回归、提交及本机安装结果见实施计划的执行记录。

## 目标与边界

保留工程已注册库中的标准封装，例如 `DSMU:1206`。更换封装时调整 PCB 实例的位置和角度，使同编号焊盘回到更换前的板上实际位置；不要求实例的 X/Y 或角度数字不变。

不新增适配封装库，不生成旋转或偏移的库副本，不修改标准库文件。暂停的方案 A 源码已做非破坏式备份，不能作为方案 B 安装或发布。

本次仅支持用户明确选中的器件，不执行整板原理图导入、不新增删除其他器件、不修改现有走线或网络定义，不自动执行 DRC 修复。

## 用户流程

1. 在封装管理的“替换库封装”页选标准库封装；选库页保留库定义比较。进入独立 PCB 更新预检后，显示当前 PCB 实例与目标实例的原位对比、补偿后的 X/Y、角度和焊盘中心最大偏差；不再出现“适配副本”保存项。
2. 保存工作台修改时只保存目标完整库标识和待更新信息，不写 PCB 或库文件。
3. “同步原理图”仍只同步原理图字段，不附带修改 PCB。
4. 新增独立操作“更新 PCB（所选器件）”。选择行后先预检并展示确认清单，说明将修改的位号、封装及位置角度；未确认的器件继续保留未确认状态，不将更新成功等同于料号电气兼容。
5. 明确确认后在当前打开的目标 PCB 中替换封装几何并补偿放置，回读验证。成功后保留为 PCB 编辑器的未保存修改，由用户正常保存；不默认保存用户整板的其他编辑。
6. 成功修改应作为一个 KiCad 撤销步骤；同时在工程外保存更新前恢复材料。批次没有全部通过时，不显示成功或清除待更新状态。

首次版本要求目标 PCB 编辑器打开、IPC 可用且工程身份可核验。条件不满足时提示打开目标 PCB 或启用接口，不自动关闭编辑器、覆盖磁盘 PCB 或终止进程。

## 原位基准

以当前打开 PCB 的实时实例为准，读取位号、器件 UUID、原理图关联路径、完整封装标识、正反面、实例位置角度、逐编号焊盘坐标和网络，以及文本放置和锁定状态。

文件路径、编辑器实例与当前工作台工程必须一致。不能仅按位号、窗口标题或默认 IPC 地址选择板。PCB 未保存的用户修改不能被磁盘旧版本替代。

预览和执行分别读取实时数据。其间用户移动了器件、更换了封装、修改网络或库源文件时，旧预览失效，要求重新预览。不使用旧快照覆盖用户后续编辑。

如果器件已经被手动更新并错位，本功能不能判断历史正确位置，也不提供自动历史恢复。预检明确以当前 PCB 焊盘位置为基准；恢复旧位置须另行核验更新前快照，不能把当前错位数据当成历史正确原位。

## 计算与判定

使用编号一对一匹配目标标准库焊盘与原实例焊盘。求解保持原正反面的二维旋转和平移，不自动交换 1/2 脚，不缩放，不推断额外镜像。

实例的新 X/Y、角度允许改变；验收对象是各编号焊盘的板上世界坐标，而不是实例属性数字或外框中心。正反面坐标转换交给经验证的 KiCad 原生几何能力处理。

圆形与方形焊盘不要求形状相同；尺寸、钻孔和层差异必须显示，不能将位置一致当成制造或电气兼容。重复编号、缺失编号、方向歧义或无法支持的对象直接阻止自动更新。

自动原位匹配的初始计算容差设为 0.001 mm；这是数值验收阈值，不是电气或制造兼容标准。超过此阈值显示具体偏差，并阻止自动更新，不移动走线或悄悄缩放封装。等效测试夹具实际更新后的逐焊盘误差要求不超过 5 nm。

## PCB 写入与保护

优先使用本机 KiCad 支持的实时接口。实现前必须在一次性工程验证“替换标准库定义 + 实例位置角度补偿”能保留器件 UUID、原理图路径、逐编号焊盘网络、正反面及用户放置文本；不能只证明移动接口存在。

禁止通过删除再重建器件来绕过关联保留问题。禁止直接调用整板更新对话框后，把未选中器件的变化当成选中更新的一部分。

执行前完成整个所选批次的能力检查与源版本检查；存在不支持项时先停止该批次，不边写边发现不可处理项。锁定器件默认阻止修改，要求用户先解锁。

备份先完成，再在一个可撤销提交中写入。回读校验目标库标识、UUID/关联路径、位置补偿、正反面、焊盘网络、未选中器件和原有走线。发布前失败撤回本插件暂存批次；发布回执丢失先只读重连核验，不重复写入。发布后无法确认结果时保留恢复材料并明确报错，不自动执行可能撤销用户后续编辑的通用撤销，也不覆盖整板或声称成功。

若接口不能可靠保留上述信息，应停止这条实时路径并报告限制，不能静默回退为关闭编辑器后改磁盘文件。

## 状态与数据

分开记录“待同步原理图”和“待更新 PCB”。只有实时回读通过，才能在本次任务结果中显示 PCB 编辑器已更新；同步原理图成功不能直接清除 PCB 待更新记录。主表持久状态徽标暂不提供，每次更新均重新读取实时 PCB，不把旧记录当成当前已保存状态。

预览令牌绑定工程、编辑器会话、位号 UUID、目标库文件版本和源实例快照。更新结果按位号记录，允许同一行的不同 PCB 实例分别计算补偿；不能要求它们共用一个偏移过的库条目。

更换库封装不附带覆盖 C 编码、Value、Comment 或物料参数；实际换几何沿用待确认规则，不能因一次 PCB 更新自动确认选料。

## 实现范围

- 独立的 PCB 会话与事务适配模块，隔离 KiCad 接口、工程身份检查、实时读写、提交及回读。
- 纯计算的原位匹配模块，复用现有编号、单位及几何校验，不把 PCB 写入混入计算函数。
- 独立的 PCB 预检、执行和任务状态接口；前端复用封装对比控件及现有任务轮询。
- 暂停方案 A 中可复用的测试夹具保留，适配副本发布逻辑不混入本方案。

## 验证与交付

先进行一次性工程能力验证，再按测试先行实现。覆盖原点偏移、90/180 度及任意角度、正背面、相同中心但不同焊盘形状、多位号不同放置、编号冲突、间距不符、未保存实时修改、锁定、源变化、接口断开、回滚和重复执行。

实际执行“工作台选标准库封装 -> 同步原理图 -> 更新所选 PCB -> 保存 -> 重新打开”流程，核验标准库内容未改、器件关联和网络未丢、焊盘世界坐标保持、未选中器件和原有走线不变。生产 L9 只可用于只读评估，不作为写入测试对象。

通过完整回归与独立代码审查后，按仓库规则提交、推送并重新安装，校验安装文件；正式公开更新发布另行遵守版本与 Release 规则。
