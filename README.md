# KiCad Component Selection Workbench

主表统一显示“待同步设计”：区分待同步原理图、待同步 PCB、两者待同步及 PCB 待核验，显示具体位号与差异；顶部按组和器件分别统计，筛选与导出范围一致。状态只读比较已保存 PCB，不打开或关闭 KiCad；同名封装的几何需要实时预检证据，保存结果未知、关联或读取失败不冒充已同步。PCB 未完成不会因原理图先完成而消失，核验记录保存在工程外，重启仍有效；PCB 实例或目标库改变后失效。

同步窗口区分“核对范围”和原理图、PCB 的实际差异数量。自动流程失败或重新预检后仍展示本次 PCB 差异清单，只提交确有变化的器件。KiCad 对闭合多边形省略冗余末点时不再误报整批失败，真实坐标、焊盘、网络和身份变化仍严格拦截。

“同步设计”保留同一轮自动流程：中途连接失败后，重新预检通过即可继续 PCB，不再点第二次“继续同步 PCB”，也不重写已完成的原理图。封装管理保存的手动配准直接沿用，同步窗口不再重复提供全局对齐选择。放弃端子、锁定换几何或来源变化仍暂停处理；保存结果未知时不自动重放事务。

同步读取目标库使用私有 Windows 桌面，不再靠隐藏普通 PCB 编辑器窗口避免闪现；隔离失败即停止，不回退到当前桌面。读库进程及其辅助进程仅属于该临时任务，结束后回收；库定义按文件内容、完整库名和板面缓存在本进程，最多保留 256 项最近使用结果。

库存支持“开始查询 / 暂停 / 继续查询”，进度按工程保存到工程外缓存；关闭或重开后可继续未完成项，不自动联网重启任务。默认只补查未查、失败和超过 24 小时的结果，可切换为 1 或 6 小时；“刷新全部”明确重新联网。同 C 编码只查一次，优先未查/失败和最旧结果，最多 4 个料号并发，国内商城读取最多 2 个并发，并与国际接口重叠。行内显示成功查询时间及近期/过期/失败状态，失败保留旧数量与旧成功时间，不冒充新结果；不修改选料、确认状态或 CAD。

封装仅改名的来源核验兼容 KiCad 保存时将实线 `default` 写为 `solid`，不会把这种等价格式变化误报为几何不一致。旧记录混用两种写法时，必须从工程外恢复材料找到 SHA-256 与原记录一致的 PCB，并核对原实例后才能恢复等价证据；没有可信备份或存在真实移动、焊盘/图形变化时仍要求重新预览。已完成改名再次同步不重复写入，真实换封装的焊盘偏移仍需确认。

封装预览支持以鼠标位置为中心滚轮缩放（25%～1600%）、切换滚轮平移、右键拖动画面、放大/缩小、适应窗口和展开预览。叠加与并排始终同比例；这些查看操作不改变封装几何或配准参数。

PCB 同步保存采用独立的 60 秒回复等待，UI 持续显示真实阶段与等待耗时；保存请求不自动重发。若回复超时，再进行最多 30 秒只读核验，仅在原会话实时内容与磁盘一致时继续重开。无法确认时保留编辑器、恢复材料和原理图成功结果，显示“PCB 已更新，保存待核验”，不重复更新或强制关闭。

封装自定义名称会在保存前校验并显示具体原因。“封装名称”只填条目名，库名在“目标封装库”选择；不要填写 `DSMU:` 前缀或 Windows 文件名禁用字符（如 `*`，尺寸可写 `x`）。保存失败或取消同名冲突选择时保留编辑界面、名称、焊盘映射及手动位置，可直接修改并重试。

库封装和立创封装支持统一手动焊盘对应、拖动、旋转、中心/1 号对齐与自动定向。可保留目标额外焊盘，也可明确放弃原端子；放弃已接网端子须在 PCB 预检再次确认，原有走线保持不动。手动适配另存至工程库，原库保持不变。详见[封装调整](tools/docs/part-selection.md#手动焊盘适配)。

主表支持按 Comment、Value、Footprint 和页面组合筛选。行号旁的规格警告核对已选 C 编码的标称值和封装尺寸与已保存原理图，等效单位不会误报；参数不足会标为待核对，并具体说明是原理图字段未填、原始文本无法唯一解析、商品字段未提供/冲突，还是封装名称无法自动比对。电容 Value 明确写出 C0G/NP0/X7R 等介质要求时也会核对，C0G 与 NP0 等效。阻容默认搜索使用简洁的值与尺寸，电阻候选支持温度系数、工作电压参数筛选。

第一列的 `?` 表示“规格待人工确认”，不是已经发现错料。点击可查看原因、需补充的封装信息和处理建议；封装名称不足时建议保留当前本地封装，不能凭本体尺寸猜焊盘间距或钻孔。警告为只读提示，不改变原有确认状态，也不自动替换或写入 CAD；尺寸相符不代表完整电气或封装兼容。

电感 Value 支持感值及 `Rated Current`、`Saturation Current` 标签；默认搜索只用感值和尺寸，缺失电流可标为 `not specified`。电流要求仍需人工审核，不作为已通过规格检查的结论。

Value 旁的左箭头可从当前主料“物料参数”逐项补充阻容感规格，勾选后预览再应用。默认勾选 Value 已包含的参数类型，未勾选项目和特殊备注保留；缺失或冲突参数不可复制。不改 C 编码、确认状态，不自动同步 CAD。电阻 `5.1k, 5ppm` / `5.1kΩ, ±5ppm/℃` 均可解析标称阻值，温漂、电压、精度等要求仍需人工审核。

本地库存与多套用量核对：在“数据 → 导入本地库存…”预览 Excel，将“同型号已购合计”作为当前结余；同一编码重复明细不累加。工具栏可修改套数，“选料 / 库存”列分别显示商城库存、本地库存和发货交期；有库存不代表立即发货，不相加或自动扣减。本地无记录的有效 C 编码显示 0，读取失败或数量冲突显示待核实；无编码显示 —。跨行共享库存和需求计算仍保留。非 C 编码采购料须明确匹配后计入。[本地库存教程](tools/docs/part-selection.md#本地库存与套数)。

本地库存可直接在主表输入数量，停止输入 600 ms、Enter 或离开输入框即自动保存；同 C 编码跨行同步显示。空白或非法数量不保存，失败保留输入；重试遇到其他窗口修改需确认最新数量。不改变选料确认状态或 CAD。顶部库存工具只显示查询／暂停／继续、选项菜单、本地库存和套数；有效期与刷新全部收进选项菜单。

“库存异常/低库存”同时包含明确无法在 4 小时内发货的物料（如 24 小时、1～3 或 9～14 个工作日），即使商城总库存很高也纳入，并显示“交期异常”；真实库存和交期照常保留。明确存在可立即发货数量的分批供货不按全量延迟处理，缺少交期依据仍显示待核实。页面筛选和 BOM 对应范围导出采用同一规则，不改变确认状态。

支持不同工程的原理图属性命名：在“设置 → 工程设置… → 原理图字段映射”使用自动识别或手动指定，缺少的物料参数等字段在同步时创建。配置按工程保存，Value / 封装的自定义属性与 KiCad 内置字段保持一致。详见[字段映射](tools/docs/part-selection.md#原理图字段映射)。

独立于工程的 KiCad 10 选料插件，提供本地工作台、立创候选与库存查询、主料/备选料/订货记录、封装对比和原理图字段同步。程序可服务不同工程；CAD、BOM、人工记录和工程库由各工程保管。

“更换型号”使用独立工具窗口，可拖出工作台或移到另一块屏幕，使用系统标题栏缩放、最小化和关闭。点击工作台空白处可收起；点击右下角恢复条或同一行“更换型号”，保留搜索、结果和筛选。退出工作台会一并退出工具窗口，保存或转换过程中会提示等待。

行内同步差异中的物料参数仅显示“物料参数更新”，完整参数仍保留并同步。
同步预检与主表使用一致的当前料号参数来源：优先已保存的同料号参数，否则使用对应 C 编码的缓存；预检后参数变化须重新核对，库存数量变化不影响已确认预检。

页面初始化失败且没有可编辑行时，窗口关闭可直接安全退出所属空闲后台；已有编辑或后台忙碌时仍保留保存保护。

数据源读取失败会显示原因，可点“重新读取”重试；列表未加载时同步和库存查询不可用。筛选无匹配时可一键清除筛选，保留原有勾选。顶部菜单支持方向键、Home/End、Enter/空格和 Esc，保持紧凑布局。参考依据见 [设计核查](tools/docs/design-review.md)，可复用检查见 [测试说明](tests/README.md)。

## 安装与启动

顶部只保留“同步设计”按钮，范围可选择所选行、筛选结果或全部器件，行内入口只处理本行。自动检查两侧实际差异，原理图已一致就直接处理 PCB，不重复写入。已通过封装管理选定且目标文件未变化的普通替换自动继续，不再重复要求几何/偏移确认；未知操作、锁定换几何、缺失/重复编号和放弃端子仍拦截或要求专项确认。旧分阶段接口保持兼容。

封装管理按当前完整 `库名:封装名` 批量处理本工程全部引用器件，不受当前筛选或物料分行限制；应用前列出影响行数、全部位号并要求确认，其他库的同名封装不包含在内。预览后引用范围改变则拒绝应用。批量只改封装及相关撤回记录，不继承目标行的选料、不改各位号 C 编码、Value、Comment 或参数；各 PCB 实例仍单独预检与更新。

同步窗口常驻显示实际阶段、完成/失败/跳过状态和耗时；已一致的设计跳过无必要的保存关窗。写入及回读成功与重开定位分开记录，定位失败保留已同步结果，使用“仅重试打开 / 定位”，不重复写入。

PCB 未打开时，通过核验当前工程的 KiCad 工程管理器打开，不再启动独立 PCB 编辑器；已打开的正确工程 PCB 直接复用。预检和写入显示动态进度条、当前步骤、总耗时及可展开的阶段耗时。原生操作没有可靠百分比时不编造完成比例。

差异区分字段更新、封装仅改名、更换封装及待核对，无变化器件不铺在表格中，也不进入 PCB 写入事务。首次改名严格核验来源，目标名称已生效后不再用历史来源约束后续 PCB 编辑，不恢复旧几何；同名的实际换几何仍完整核验目标。缺失与空白字段不制造无意义更新。PCB 更新包含映射属性，只处理实际差异，不改网络或走线。

PCB 自动保存后核对完整实时内容及磁盘内容，保留当前 PCB 编辑器和原生撤销栈，不再为核验而关闭重开工程。确需外部修改原理图时仍安全保存关闭工程；PCB 写入前仍保留 KiCad 10 原理图暂关保护，结束后恢复一次。保存失败、对话框或身份不明时停止，不强杀、不丢弃编辑。

封装管理、同步预检、设置、库存导入等工具使用可移出工作台的原生独立窗口。封装管理同一行恢复已有窗口，不同行分别打开；其他同类工具窗口复用，前进后退保留草稿。保存后局部更新主表，不重算无关列宽或替换其他行的输入框。

关闭主工作台会自动取消尚未应用的封装预览并关闭其子窗口，不必逐个关闭。正在保存或后台请求未结束时自动等待重试；其他工具未保存表单须确认放弃，拒绝时保留编辑。资料加载失败会显示原因并支持重试，不留下空白窗口。

当前 KiCad API 的事务请求缺少文档路由，原理图与 PCB 同宿主时可能误投递。插件在 PCB 写入前安全保存并暂关同工程原理图，重验预检后提交，再恢复原理图；保存失败不写 PCB。原理图同步后只重新打开，不自动执行搜索；位号链接仍可显式搜索定位。

已完成的封装替换按当前实例几何核验，不重复替换；库路径或内容改变会重新核对。没有改动时不关闭原理图。发现 PCB 文档锁或无法确定进程归属时停止自动打开，不重复启动编辑器。

历史手动适配记录中的“额外焊盘”仅在首次新增时要求不与原理图端子冲突。目标封装已生效后，重新核验目标文件、完整编号、几何和姿态，保留后来连接的焊盘网络，不清空或重复添加。几何完成识别兼容既有纳米级舍入引起的图形排序变化，仍核对全部内容与重复数量；实际移动、缺焊盘或库变化仍需重新预览。冲突提示包含具体位号。

列表列宽可在“列表视图 → 列设置 → 自动调整列宽”中重新适配，列设置会自动记忆。

主表“选料 / 库存”合并选用物料与本地库存。输入 C 编码自动保存后立即查询，不必按 Enter；可直接删除编码，查询失败可点状态重试。供货渠道、订货链接、真实交期及查询时间折叠在“供货详情”，MOQ/MPQ 和价格仍独立显示。库存查询不改变确认状态，当前与默认列布局自动迁移。

Footprint 输入框旁的图标可独立预览和管理封装：窗口先显示，数据后台读取；“替换库封装 / 替换立创封装 / 库封装改名”在同一窗口切换，前进、后退保留搜索和编辑。选库列表与对比图同页，支持叠加、并排、图层及透明度；“库封装改名”仅显示改名前、改名后两个完整的 `库名:封装名`，不等待图像或联网转换。保存仅修改 Footprint，保留其他选料字段，不自动同步 CAD。真正换几何回到待确认，仅改名保留确认。候选搜索停止输入 600 ms 后自动执行，Enter 立即搜索；候选封装选项为不替换、替换库内部封装、替换立创封装，默认不替换。

标准库封装在封装管理选定后，点击“同步设计”即可依次完成必要的原理图和 PCB 更新。库文件保持原样，不生成适配副本；PCB 实例按所选对齐方式补偿位置和角度，不移动走线。保存核验后保留 PCB 窗口，工程外保留恢复材料。从原理图或 PCB 入口均可，需启用 IPC。详见[所选器件原位更新 PCB](tools/docs/part-selection.md#所选器件原位更新-pcb)。

PCB 预检默认“中心对齐”：按当前实例铜焊盘中心包络对齐并校正方向，保留标准库几何，允许焊盘移动。逐焊盘最大移动量会列出，确认后更新，原有走线不移动，需自行检查连接与 DRC。可切换“焊盘原位”，要求每个编号焊盘偏差不超过 0.001 mm；上段的逐焊盘留在原处仅指这一严格模式。

第一次拿到仓库链接，按 [从 GitHub 下载到手动安装](tools/docs/kicad-plugin.md#从仓库链接手动安装) 操作；不需要原作者的工程、BOM 或 tools 副本。支持 Git 克隆和网页 Download ZIP 两种获取方式。

支持 Windows 10/11、Python 3.10+；独立窗口使用 WebView2 Runtime。网络查询需要联网，外部商城快捷页面使用 Edge 或 Chrome。KiCad 插件入口需要启用 IPC API。安装包不含工程文件，也不依赖 FPGA 或 PCB 3D 工具。

将本仓库单独检出到工程之外，例如与 `SMU_DL_v2/` 并列。从本仓库根目录执行：

```powershell
python -m pip install -r tools/kicad_plugin/desktop-requirements.txt
python -B tools/kicad_plugin/desktop.py --project "E:/path/to/project/project.kicad_pro"
```

也可双击 `tools/启动器件选料助手.bat` 选择工程，或向它传入 `--project` / `--config`；无参数时不绑定任何固定工程。已有配置可直接使用：

```powershell
python -B tools/kicad_plugin/desktop.py --config "E:/path/to/project/BOM/选料工作台/工作台配置.json"
```

仅保留独立工作台，不再提供浏览器模式或启动失败后的浏览器回退。关闭窗口会停止库存队列、保存行内编辑，再退出本工程后台；也可使用“文件 → 重启工作台 / 退出工作台”。慢库存请求与排队等待可取消，迟到的联网结果不写缓存、不改确认状态，不再要求先“重新读取”才能退出。搜索、转换或同步未完成时仍会提示等待，保存失败时保留窗口及编辑内容。同工程同编码的并发库存请求合并完整联网链路，不以旧库存代替刷新结果。

安装到 KiCad 工具栏或构建 ZIP，见 [插件安装](tools/docs/kicad-plugin.md)。轻量安装包不内置转换器，完整版准备方法见 [转换器说明](tools/docs/easykiconverter.md)。

替换库封装默认复用原库名称，预览拖动不另存适配副本。需改端子对应或保存手动几何时才勾选“保存工程适配封装”。跨行同物料的保守批量统一使用 `tools/unify_footprints.py --config <工程配置> --report <工程外报告.json>` 先核对，增加 `--apply` 仅保存已证明铜皮等效的工作台修改；真实间距差异及选料冲突跳过，原理图和 PCB 仍需正常同步。

通过“设置 → 插件更新…”检查 GitHub 正式发布版本，先“下载更新”，校验完成后按需“重启并更新”，也可关闭面板继续工作；已校验的包不重复下载。支持“自动下载，退出工作台后更新”。默认仅启动时检查提醒，不自动安装；也可关闭自动检查。显示当前/目标版本、成功检查时间、任务进度与错误，更新方式保存失败时恢复原选项。更新校验下载包 SHA-256、版本及插件标识，保留转换器与工程数据，目录切换失败恢复旧安装。源码运行使用 Git 更新，不通过菜单覆盖。[更新说明](tools/docs/kicad-plugin.md#在线更新)

更新检查优先读取 GitHub 正式发布下载清单，不依赖 REST API 匿名额度，无需 Token；成功检查启动缓存 6 小时、手动缓存 1 分钟。403/429 失败增加工程外持久等待记录，显示可重试时间，等待期间不会因点击或重开窗口继续请求。公开软件参考见 [更新设计核查](tools/docs/update-design-review.md)。

更新检查和下载不会占用工具窗口的操作锁；期间仍可打开封装管理、工程设置等窗口，退出或重启会提示等待更新任务完成。HTTPS 意外中断仅自动重试一次，证书错误不重试、不关闭证书校验；持续失败会提示检查网络或代理，当前安装和工程数据不变。

## 工程数据与路径

PCB 锁定不妨碍只读预检、无需更新、仅改封装名或物料字段；更新后保持锁定、位置、方向和几何。真正更换封装几何时，逐位号提示先在 PCB 解锁再重新预检，不自动解锁、不跳过器件后冒报整批成功。进度区将读取完成和操作受阻分开显示。

每行提供“撤回修改”：预览后撤回工作台尚未同步的字段和选料修改（包括仅改封装名），新编辑的快照重开仍有效，同步成功后清除；不修改原理图、PCB 或已导入的工程库。旧快照缺失或跨越同步时明确提示按当前已保存原理图恢复，不回滚已同步历史。工具窗口支持 Esc，优先关闭最上层，保留未保存编辑及任务保护。详见[选料与撤回说明](tools/docs/part-selection.md#选料与确认)。

更换型号先显示搜索列表，再后台补取对应商品详情页的完整分类参数，支持参数筛选；电阻显示温度系数/工作电压，电感显示 DCR/类型。参数区标明来源，并区分正在补取、读取失败、详情页未列出，失败可重试，不将列表缺项误判为厂商未提供。订货渠道规格与商城主料独立；选用时保存补齐后的参数。

封装转换和“仅改名保留几何”均优先读取已保存 PCB 中所选位号的实际封装，还原局部坐标、旋转和正反面；找不到 PCB 实例时才退回原理图绑定库。仅改名以铜皮焊盘的编号、局部坐标和方向作为共用判断；丝印/用户图形有差异时提示，并统一采用所选基准封装版本，不联网转换。同一行基准的焊盘中心允许最多 0.000020 mm 的绝对距离差异，兼容历史小数及原生坐标还原误差；超限仍须拆行，不拟合掉局部原点、旋转或镜像差异，不改变 PCB 更新的独立安全阈值。同名且内容相同直接复用；内容不同则提示“已有同名封装”，可另存新名称或确认影响后备份覆盖，不自动添加 C 编码后缀。立创转换按同编号焊盘校正方向并对齐中心，可手动选兼容旧库作为恢复基准。不要求圆/方焊盘外形完全重合，间距差异提示人工核对，不自动缩放或镜像。预览支持同尺度叠加/并排及独立图层显隐。保存只绑定待同步 Footprint，不直接改 PCB。

“设置 → 工程设置… → 原理图跳转”可选择跳转后鼠标“返回原位”（默认）或“留在原理图画布”，按工程保存并立即生效。位号跳转保留 KiCad 当前窗口大小与最大化状态，仅在最小化时还原。“更换型号”设置可控制打开候选窗口时是否自动打开网页搜索，默认开启；候选窗口中的手动按钮称为“网页搜索”。

候选搜索区将查询状态、筛选条件和结果数量放在紧凑信息栏中。查询期间显示“查询中 / 已返回部分结果”，初始渠道暂未匹配时仍会显示后续“补充检索”的进度和来源；只有整个搜索完成且结果为空才提示未找到匹配器件。

确认料状态就地更新，不再重新加载整表；每次确认会记录服务端确认时间，并在列表中显示，状态后来改回待确认时仍保留上次确认时间。切换筛选组合时会记住各组合的滚动位置。Comment、Value、Footprint 自动保存后立即显示未同步的旧值 → 新值，与按 Enter 的反馈一致，改回原理图已保存值时清除对应差异。Enter 仅在分组确实变化时重新合行，并保留所在行的屏幕位置。

物料参数摘要保留电气参数，显示封装和未重复出现的品牌；包装方式与器件类别不写入摘要，也会同步应用于原理图 Description。

同步提示合并同一行的重复变化，不再重复列位号和 C 编码链接。Footprint 输入框只显示封装名称，共用库名（如 DSMU）放在列表头；存在多个库时各行单独标出。保存与同步仍使用完整的 `库名:封装名`，输入完整标识可切换该行库，空白保持为空；不会因改其他字段而丢失库名。

Comment、Value 或 Footprint 自动保存完成后会检查分组；当字段变得一致时无需按 Enter 就会合并，临时拆行也会在字段一致后合回。只有分组成员变化才重绘表格，并保留当前滚动位置。

手动编辑并入已有目标行时，优先沿用目标行的唯一主料、参数、备选、订货及确认状态，不因来源 C 编码不同而清空。备注按位号保留，来源旧选型先备份到工程外；目标本身存在多编码冲突时不任意取第一个。合并后的原理图改动仍需确认同步。

正式数据统一使用中文文件名，默认放在 `BOM/选料工作台/`：`已选物料与字段修改记录.json`、`工作台配置.json`、`原理图同步记录.csv`、`立创库存与参数缓存.json`、`位号清单.txt`。导出文件使用 `采购BOM表_时间.csv`、`选料变更记录_时间.csv`；运行日志在工程外。旧标准配置首次启动会备份并迁移，保留原文件，已有自定义路径不重置。示例见 [工作台配置](examples/工作台配置.json)。

导出 BOM 表或改动表成功后，默认打开实际目标文件夹（包括自定义数据目录），不自动打开文件。打开文件夹失败不影响已导出的文件，工作台会保留成功提示及完整路径并显示打开失败原因。

采购 BOM 的前 10 列遵循立创商城模板：序号、型号、封装、参数/规格、单套用量、品牌、分类、商品编号、物料编码、位号；Comment、Value、完整 KiCad 封装标识、供货和确认/同步记录等附加列排在后面。商品编号为所选 C 编码，物料编码为企业内部编码、当前留空；单套用量不乘套数。文件仍为 UTF-8 BOM CSV，可用 Excel 打开，不包含模板示例料。

模板后的第 11、12 列为“本地库存”和“本地库存说明”：导出已导入或手动维护的实际数量，不乘套数、不扣减需求、不混入商城库存。点击导出先等待行内库存保存成功，保存失败则停止导出；同 C 编码跨行共享并注明勿重复累加。有效编码无本地记录为 0，读取失败、冲突和旧编码数据为待核实。商城交期同时读取商品卡片的明确发货标签，校验商品 ID、C 编码和型号，保留“最快”及工作日/分批数量；来源在“供货详情”，不把网页页脚广告或库存总量当作发货承诺。

无需把工程复制到插件仓库。命令显式指定工程或配置；同时指定时两者解析出的工程根目录必须一致。后端不从插件源码父目录猜测工程。

通过顶部“设置 → 工程设置…”选择原理图数据、导入 BOM、工程选料数据目录和转换器；具体文件与运行路径在折叠的“高级路径设置”中。每次启动默认读取已保存的原理图，导入 BOM 仅本次生效。选料记录、导出和同步日志默认在当前工程 `BOM/选料工作台/`，修改目录时保存前确认复制，原文件保留，目标冲突不覆盖；已有自定义文件位置不会因无关设置变动而重置。运行目录修改后可直接点“重启工作台”。[设置及迁移步骤](tools/docs/part-selection.md)

临时转换、预览和备份位于工程外同盘缓存；已注册的符号/封装库仍是工程设计依赖，不能当作插件缓存删除。目标库选择已在封装对比界面提供。
